# 博客管理端全面 UI 优化

用户在 rc.52 上线后提供分类与标签页截图，要求全面优化管理 UI。延续已明确的直接开发及验证后正式更新授权，不另设确认轮。范围为博客管理端五个页面及其对话框；保留 Vue、现有 API、手动发布和权限规则。

## 当前问题及取舍

截图显示正文与辅助文字过小、侧栏长标签裁切、空分类卡片高度固定而操作缺失、白色平面层级弱，已有文章／装修／设置也有相同的控件尺寸与间距问题。仅放大字号不能解决布局和空态；重新引入 UI 框架增加无关迁移。采用现有组件上的统一管理界面样式、信息分组与少量必要交互。

## 统一视觉

博客区域增加独立 blog-admin 标记和样式文件，避免继续堆叠修改被其他任务使用的 blog.css。桌面主体15px、辅助文本至少13px，手机输入16px；标题24–28px，主要操作高度至少42px、手机44px。细边框、柔和页面底色、白色分组面板、清楚的蓝色主操作和状态徽标，保留现有明暗主题。最大内容宽度1280px，宽屏居中，平板与手机自然换列，不以固定大高度填空。

现有 hostedNavigation 与内置博客导航两种挂载方式均可用。博客共享窄菜单通过独立选择器避免文本裁切，不修改其他应用主菜单逻辑。原有可访问名称、入口和常用测试定位尽量保持。

## 各页面

- 概览：清楚的管理标题、紧凑起步区、文章／已发布／草稿／待更新统计，真实最近文章与可用的快捷入口。没有文章时直接选稿，不增加虚假图表。
- 文章：清楚的主从关系、较宽且易读的文章卡片、搜索状态、分组元信息、发布状态及固定主要操作。详情预览、保存、发布、下架、切换时草稿保留和确认流程不改变。手机编辑器和保存操作可触达。
- 分类与标签：自适应内容面板，零项空态有明确整理文章／选稿入口；有内容时可搜索，区分没有分类与搜索无结果。点击分类／标签进入正确文章筛选并清除无关旧文章搜索。
- 站点设置：公开状态、基本信息、访问与外观、关于分组；保存条和未保存状态明确，辅助说明与正文可读，不自动开启站点。
- 装修：更清楚的设置分类、主题缩略图、表单分组、模块顺序及卡片动作；预览、草稿和发布状态集中呈现。提供可关闭的放大预览，复用同一 HTML 和真实1100／375视口，键盘 Escape 关闭并恢复焦点。保留图片裁切、历史、专题、导航和项目功能。

## 验证及发布

纯样式不写镜像测试；新增分类筛选和预览对话框交互用真实浏览器验证，保持原博客、装修及异步草稿回归。覆盖空／有内容、错误、等待、长标题、暗色、1094px截图宽度、1440px桌面与390px手机，留存前后截图。独立审查后，从正式 rc.52 的固定源码提交制作仅包含本次 UI 改动的 rc.53，备份并使用现有更新流程；保留公开开关、资料、插件状态及回退版本。
