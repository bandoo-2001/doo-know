# Git 远程知识库管理设计

用户已确认本次沟通汇总并要求执行。目标是让普通用户在网页完成 GitHub/Gitee 克隆、现有目录关联、凭据管理、提交推送、手动拉取和失败恢复。其他功能、既有资料、历史、配置和大文件恢复上限保持。安装与后台下载代理修复必须进入发行包。

## 实现边界

复用系统 Git ≥2.39、现有工作区互斥门、子进程守卫、本地 Git 插件提交预览及核心索引服务。不引入新运行依赖。核心提供仅登录账号可调用并受来源/CSRF校验的 `/api/platform/git` 管理接口；Git 插件仍负责本地预览/提交/历史，原插件API保持兼容。原生云端同步面板复用于知识库设置、Git插件设置和左下角同步入口。

初始页增加“从 GitHub／Gitee 导入”。克隆在允许目录内的独立暂存位置完成，校验提交树、目录和绑定身份后发布到不存在或已证明为空的目标目录，再绑定并激活知识库。失败保留任务回执，绝不清空既有目录。远端导入/关联流程明确告知将安装并启用Git插件；新建/选择本地目录不改变插件状态。

普通目录可初始化并关联空远端。已有Git仓库识别分支和安全远端，复用相同连接；现有不同远端不被覆盖。云端非空不自动合并或强推。提交后推送失败时保留提交，重试只推送固定已提交版本。默认不自动同步。

## 凭据及网络执行

只接受规范化的 github.com/gitee.com HTTPS 或 git 用户SSH仓库地址，禁止URL内凭据、查询参数、端口、路径穿越和本地协议。凭据独立按账号及主机绑定，使用安装认证密钥派生的AES-GCM密钥加密保存在数据区；GET只返回名称、类型、主机和是否已保存，令牌/私钥不回显。删除凭据不删除资料或历史，关联连接随即要求重新认证。

公开HTTPS仓库读取可不配置凭据。HTTPS默认令牌；通过子进程环境引用传递Authorization，禁止把凭据放入URL、命令参数、日志或.git/config。SSH高级选项导入私钥及可选口令、已核对的known_hosts；扫描结果只展示指纹供用户与官方文档核对，明确确认后才保存。始终StrictHostKeyChecking，不自动信任。明文临时认证文件为600，离开操作即删除。

所有Git进程使用守卫及互斥许可，禁用hooks、fsmonitor、交互提示、外部协议、子模块递归、Git跟踪和全局配置。远端操作拒绝仓库中的URL重写、额外HTTP头、替代SSH命令、代理覆盖、外部过滤器和include等不可信执行配置。验证目标树只含普通文件，不自动检出软链接/子模块。传输错误仅返回固定中文错误码，原始stderr不进入API或诊断导出。执行器支持AbortSignal，关闭服务时停止任务子进程。

## 同步与任务

网络操作使用持久异步任务（queued/running/succeeded/failed/needs_reconciliation），请求立即返回202，按账号和requestId幂等。每次任务记录目标目录/绑定版本、分支和提交基准，不能因超时改写为新操作。只允许一个仓库写任务；重启时不盲目重放推送或发布，标为待核对。可重新检查远端并重试推送固定提交。

状态页分别展示未提交文件、当前分支/HEAD、待推送和待拉取提交、分歧、最近检查时间和结果。没有检查过远端时显示未知，不能宣称已同步。读取连接成功不等于有推送权限；首次成功推送后才明确记录推送成功，dry-run仍需解释分支保护等最终限制。

拉取仅支持干净工作树的快进更新。先fetch到应用专用引用，比较双方提交；本地有修改、待恢复操作、分支分歧或目标树不支持时在改原文前停止。既有提交/远端配置不被重置，不使用reset --hard、clean或强推。应用互斥期间阻止平台文件写入，临近检出再次核对HEAD/工作树；更新后刷新目录与索引。当前浏览器存在未保存笔记时阻止提交并推送和拉取，提供返回保存的指引；单纯推送已提交版本说明不会上传草稿。

## 用户界面

初始页保留新建/已有目录，新增远端导入选项，按地址、认证、分支及保存位置、任务进度组织。知识库及Git设置提供“关联云端仓库”。左下角新增“云端同步”，保留“提交全部变更”；同步面板提供预览、提交并推送、仅推送、检查云端和拉取更新。明确保存/提交/推送的区别及Git不替代备份。

凭据表单默认HTTPS，SSH折叠高级区域。提供GitHub/Gitee官方教程链接、读取测试、替换/移除凭据；输入秘密不进入浏览器持久存储。错误区分地址、认证/权限、网络/超时、本地修改、远端分歧、未知结果。可恢复任务在刷新后可继续查看，避免重复提交。布局适配桌面和手机。

## 插件下载及发布

后台serve复用已保存的下载代理，显式环境配置优先；确保本地健康及内部请求绕过代理。插件安装/升级独立异步任务并显示阶段和状态，解决浏览器15秒取消而后台120秒下载的结果未知问题，关闭/重启保留可核对状态。兼容已有直接安装接口和本地部署脚本。

计划发行rc.23、Git插件1.1.0、MCP维持1.0.2。数据库兼容代次保持2，新增独立表不改既有业务结构，回退旧代码仍可读取原资料。真实生产不克隆测试仓库、不绑定新知识库、不使用用户真实远端凭据推送；凭据及远端写测试均使用隔离数据和真实本地bare仓库传输替身。CI、单元/接口、完整双端、原生安装/恢复及生产匿名只读验证通过后上线，先备份并保留原配置/插件启停选择。
