# 任务页面信息与操作整理

用户确认按本轮滴答清单对比分析实施：统一看板、详情、分组与菜单，减少重复信息和常驻控件，保持其他 ToDoo 页面的整体风格，原有功能不丢失。

## 已确定的方案

沿用现有 Vue、Ant Design Vue、主题变量、侧栏、页头、弹窗和显式保存机制。以已有清单、分组、任务、子任务模型整理呈现；不替换整体设计系统，不增加依赖，不迁移数据或部署服务。

- 清单范围在列表、看板、时间线保持明确，切换展示方式保留筛选与选中任务。全局日历入口仍可显示全部内容。
- 在具体清单内，列表按分组排列并支持折叠；未单独设置分组的子任务跟随父任务，已有独立分组保留。空分组仍能管理和添加任务，未分组任务有明确归处。
- 看板保留按状态、清单、优先级、分组、标签的原有能力。列内任务复用列表的完成、标题和非空属性表达；移除重复的常驻状态下拉、空优先级、零资料数和未安排占位。父子任务在同一列时集中呈现，跨状态/过滤结果中的子任务仍可单独出现。
- 任务行提供可点击的更多菜单及右键入口：打开、添加子任务、安排时间、优先级、移动、复制、归档与删除。触屏不依赖右键或拖动。菜单操作不改变批量选择；子树操作先完整读取成员和版本；请求失败保留可重试状态。
- 分组菜单提供重命名、相邻新建、排序与删除。删除分组保留任务；排列变更使用版本检查，新增位置只在保存时生效。
- 详情优先呈现标题、正文、已有子任务和资料摘要。未设置的日期、优先级、提醒等通过属性菜单进入；原有高级设置、重复实例、附件、依赖、标准、成果、历史、冲突恢复和保存仍可访问。
- 计划与截止仍分别表达；重复规则与本次执行的区别不被简化掉。详情有修改时仍显式保存，隐藏字段不被重置。
- 时间线保留查看与编辑功能，复杂安排工具按需展开，批量调整预览与确认保持。

## 取舍

采用用户已确认的对象内聚方案。只折叠更多字段不能解决操作分散；完全更换页面骨架会破坏风格统一。保留现有批量操作作为完整路径，增加单任务快捷入口。

## 验收

测试覆盖分组/子树排序、筛选后的父子关系、循环与重复实例、分页子树、菜单操作与批量选择隔离、旧详情字段保存、深浅色、键盘/触屏与 320 像素窄屏。保留任务开始时所有未提交工作，只修改本任务相关位置。

## 实施验收

已完成。45 个 ToDoo 测试文件、472 项测试通过；桌面浏览器 38 项、手机浏览器 14 项通过。生产构建通过；全量类型检查曾通过，但最后复核时工作区的 `tests/mcp-transport.test.ts` 出现新的类型错误（不在本次修改范围），因此不能将当前全量类型检查记为通过。已人工检查桌面、320 像素窄屏及深浅色截图。

独立评审发现的子任务右键定位、清单切换残留分组、显式子分组覆盖、搜索祖先元数据及重复分组计算问题，均已添加回归并修复。另验证了菜单关闭/焦点恢复、分页子树操作与批量选择隔离、提交期间分组草稿保留。保留重复、提醒、附件、资料、标准、成果、批量操作、日期校验及计划预览功能。

改动位于当前工作区，未提交混合变更、未部署服务、未改动数据模型。

最后补验：前端与共享模块的独立类型检查通过（使用项目已有 lunar-javascript 声明）。当前唯一验证限制为其他未提交的 MCP 传输测试类型错误；本次任务未修改该文件。
