# Excalidraw 白板设计

用户已确认直接实现：笔记内展示白板预览，右上角编辑进入完整设计页；独立白板使用特殊后缀，与 Markdown 区分。实施细节由代理自行处理。

## 文件与数据

- 使用官方 `.excalidraw` JSON 格式，场景和画布图片一起保存，最大 8 MiB、最多 10,000 个元素。源码是唯一权威数据；预览在浏览器从场景生成。
- 复用文档 ID、写入日志、纳秒版本、请求幂等、历史、移动、回收站、导入导出和备份。树中的类型仍为 note，增加可选 documentType，避免破坏现有插件契约。
- 白板只能在现有分类目录中创建，文件改名保留文件类型。白板文本索引只包含名称与未删除的文字节点，不包含 JSON 和图片编码。
- 笔记引用使用 fenced `excalidraw` 块，内容为稳定文档 UUID；重命名、移动不影响该引用。批量导出的 Markdown 同时保留该引用和白板原件。
- 白板 JSON 内的 `dooknow.id` 保存稳定文档 UUID。新知识库扫描原文件时恢复此标识，Git 克隆不依赖旧数据库；原生导入作为副本分配新标识。现有有效标识冲突时保留原文并为副本另建身份。

## 交互

- 新建菜单提供白板；文件树使用白板图标。打开白板进入全页设计工作区。
- 笔记文档编辑与阅读预览显示白板卡片，提供放大、编辑设计。嵌入编辑时保留父笔记及其未保存草稿和滚动位置，完成后刷新预览。
- 设计工作区有返回、文件名、保存状态、手动保存、原文件和 PNG 导出；官方画布按需加载，中文、浅色/深色主题。自动保存短暂合并变更，Ctrl+S 可立即保存。
- 保存失败保留草稿；409 冲突不覆盖磁盘，提供重新读取和下载草稿；网络结果不明重试使用同一请求 ID。关闭及页面离开保护未保存内容，草稿在本地恢复。
- Mermaid 代码支持预览，并可以转换为新的白板副本。原 Mermaid 保留；转换后的自由设计以白板保存。
- 分享端只读：白板自身的分享可读其场景；笔记分享仅允许读取该笔记明确引用的白板。取消分享或删除白板立即阻止读取，不开放所有私有白板。

## 边界与验证

- 验证场景格式、大小、元素 ID/坐标、图片类型和链接，拒绝主动脚本与外部图片数据；无效导入不能覆盖原件。
- 核验实际创建、刷新重开、图形修改保存、图片保留、草稿恢复、冲突、幂等重试、改名移动、回收站恢复、导入导出、分享撤销和两种编辑器的往返。
- 复用当前工作树中已有的编辑器与设置页改动，不提交混合变更、不部署服务。
