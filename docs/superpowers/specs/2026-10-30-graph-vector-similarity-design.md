# 知识图谱真实语义相似

用户明确要求实现真正语义相似，优先复用现有向量模型，不再只依靠词项重合。继续在独立 `codex/knowledge-graph` worktree，基线 `8126d74`；保留已验收 AntDV 界面，不部署、不修改实际知识库或凭据，不安装新的模型。

## 选择

现有 BGE 本地模型产出 512 维、L2 归一化分块向量，FlatFileStore 已把它们保存在 `vector_cache`、段文件和 active generation 中。选择直接复用有效缓存，按非重叠正文覆盖字节加权平均分块向量并重新归一化，计算笔记间余弦相似度。避免重复嵌入或为每篇笔记发一次全库 flat-search HTTP；不增加独立向量模型或常驻服务。

这是真正的 embedding 相似度，仍只表示语义接近，不证明事实一致、依赖或因果。删除当前 similarity 边的 Jaccard 分支，向量未就绪时明确报告，不把词项算法作为隐式降级。

## 有效性与权限

读取当前 desired embedding space 与 active generation，要求空间匹配。候选限定当前获准 Markdown 笔记、active/nonconflict/source-current 文本及向量索引；联表 chunks、vector_rows、vector_points、vector_cache，检查 note/hash/revision/inputHash/space/generation 完全一致。每篇全部当前活动分块都有有效 2048 字节向量、完整覆盖及合法跨度后才计算代表向量；缺失、NaN、零向量或预算不足不得伪装为完整。

选择候选和统计前执行严格 ACL，不让隐藏笔记影响边、依据或公开 revision。结果发布前再次验证来源、文件身份、generation/space/epoch。向量服务离线但现有发布缓存完整时仍可计算，不为读图请求启动模型或发起嵌入。

## 图谱接入

新增独立 `vector-similarity.ts`，提供轻量 status 与异步 prepare/assertFresh/close。prepare 返回 note 节点、相似边、双侧原文证据、相关 noteIds、状态与内部版本围栏。查询按需计算，分批让出事件循环，有候选/向量字节/比较次数/时间/队列上界，并显式 truncated。默认余弦阈值 0.65，每篇最多三个高分邻居；阈值独立于模型关系置信度。

候选来自全授权有效向量笔记池，不能只比较已有词项/引用邻居。聚焦笔记须能发现没有共同词项、实体或显式链接的向量邻居，并把对方加载到子图；可在有界范围内扩展两层。配置/索引发布后公开状态 revision 更新，但不泄漏未授权来源变化。

每条相似边包含对称稳定 ID、cosine 元数据、embedding space 与维度；证据 method=embedding，来自双方实际参与计算的当前分块，摘录与行号准确。尽量选择与对方代表向量接近的分块；否则明确是参与计算的示例片段，不声称最相近句。

## 界面

沿用当前 AntDV 筛选/Alert/详情布局，把开关改为“显示语义相似（向量）”；仅启用后显示独立相似阈值和准备状态。未配置或缺索引时指导到“设置 → 搜索与索引”，不要求配置实体抽取聊天模型。详情显示余弦分数与向量来源，避免把它格式化成事实概率。原有引用、模型关系审核及人工决定不变。

## 验收

单元覆盖真实向量读取链、加权/重叠处理、完整分块、空间切换、删除/变更/冲突/写入状态、ACL与scope revision、损坏向量、预算/取消和证据。集成覆盖完全不同词项但相似向量能连线、同词而向量正交不连、聚焦发现非词项邻居、索引完成后自动刷新、缺模型状态。
