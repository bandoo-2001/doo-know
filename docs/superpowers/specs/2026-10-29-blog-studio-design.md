# 博客综合升级设计

用户已明确授权按上一轮推荐方式直接全部开发，不再停在方案选择或等待确认。本轮沿用 Vue 3、Fastify、SQLite、现有单主人博客及手动发布快照机制。

## 目标与方案

将博客完善为可装修的个人站点／数字花园：个人身份、三套实际不同的主题、首页模块、专题、发文检查与阅读发现一起落地。比较仅换皮肤、模板加模块、自由区块编辑三种方式后，采用用户认可的“预设主题＋首页模块”；配置自由度足够，编辑复杂度可控。现有知识库和博客内容继续复用，不引入第三方执行代码、付费服务或新的运行依赖。

## 站点装修

三套主题 journal（文字博客）、magazine（卡片杂志）、profile（个人主页）；配色、衬线／无衬线字体、内容宽度、卡片样式。个人资料含姓名、短介绍、简介、头像与横幅。导航、社交链接、项目和友情链接可编辑。首页提供介绍、精选、最近文章、专题、项目、友链六种模块，可添加、删除、排序、隐藏、设置标题与数量。

装修配置独立保存为草稿，预览使用公开站同一渲染器；确认发布后才影响访客。提供历史记录及将历史版本恢复到草稿。新增媒体持久化保存，草稿图片只在认证预览中可见，公开端只能访问当前已发布配置引用的媒体。仅允许受限图片类型，校验格式与大小；禁止 HTML、脚本及危险链接。站点关闭时所有公开入口继续关闭。

## 阅读与专题

主页与完整文章列表分开；保留 /blog?category= 和 ?tag= 老链接兼容。文章列表支持公开内容范围内搜索、分类、标签和真正分页。专题包含独立 slug、介绍、按顺序选择的文章；专题及其详情仅呈现已发布文章，撤下文章即时消失。文章页增加专题位置、上下篇、相关文章、分享、代码复制、便捷目录、阅读时间及封面分享元数据。关于支持安全 Markdown。保持可访问语义、键盘操作、移动端无溢出和现有明暗适配。

## 发文与知识库

首次发布前允许编辑 slug，首次公开后固定。封面可从笔记附件选择或上传，提供裁切；仍沿用原有附件捕获，上传本身不自动公开。发布前提供线上／待发正文对照与未公开内链、失效引用、缺失图片诊断，列出可能需重发的关联文章。诊断不扩大调用方目录或博客权限，也不替代发布时的原稿、资源和授权复查。

## 持久化、兼容与边界

新表采用幂等迁移，默认配置能兼容已有实例。新装修状态与媒体随现有 SQLite 备份和可移植知识库保存／恢复；恢复副本继续默认关闭博客，不自动公开。扩展 MCP 管理能力时沿用 blog:read/manage/publish 分权，不给旧凭据扩权。公开文章摘要查询不读取全部正文；关闭／下架保持立即生效。

只修改本任务文件，保护现有未提交工作；当前目录已经是独立工作树。仅用隔离夹具和临时账号验证，不修改正式知识库、正式服务、发行包或远端分支。

## 验收

装修草稿不会改变访客页面；发布可见、历史可恢复；匿名与无 CSRF 写请求被拒绝。三套主题有不同结构，所有模块和专题能实际配置、预览和展示；缺失／下架内容不泄漏。图片上传、裁切、引用、备份恢复走通。搜索、分页、专题顺序、文章互链、slug、发布检查通过行为测试。旧博客、MCP、导出恢复回归通过；电脑／手机实际浏览器覆盖装修到公开访问全流程并留存截图。
