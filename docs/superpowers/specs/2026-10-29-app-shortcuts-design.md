# 应用加入左侧菜单

用户已确认：应用卡片支持加入/移除左侧菜单，点击菜单直接打开应用；按账号保存在当前浏览器。

## 方案

采用独立的本地账号偏好，沿用编辑器偏好的初始化时机，避免修改后端或与编辑器重置耦合。账号同步需要服务端持久化，本次按用户选择不采用。

## 行为与边界

- 博客、To Doo 卡片各有独立的加入/移除按钮，不与打开应用的按钮嵌套。
- 左侧菜单按加入顺序显示应用图标、名称，并准确高亮当前应用；默认无固定应用。
- 快捷入口打开应用概览，复用原有笔记上下文保存和 To Doo 未保存内容确认；取消离开不改变当前页面或地址。
- 刷新、重新登录同一账号保留选择，不同账号隔离；损坏或过时的存储值过滤，存储不可用时允许本次会话使用并提示。
- 桌面菜单可滚动；手机菜单换行，不导致页面横向溢出。
- 不改账号、知识库、应用数据或正式服务；保留 HTTP UUID 修复。
