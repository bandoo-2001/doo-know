# 彻底卸载资源清理

新增 `dooknow uninstall --purge`，默认卸载行为保持不变。清理当前配置管理的插件目录、检索运行环境（含 Python 依赖）、模型、检索下载缓存及 `dataRoot/indexes`；随程序附带的依赖仍由原卸载流程移除。

保留知识库原文、备份、数据库、配置及密钥，避免备份失去恢复能力。外部向量服务、自备 Python/模型不属于自动清理范围。

采用现有卸载命令的可选参数，比额外清理命令更符合使用方式；不删除整个安装或数据根目录，因为里面可以保存备份和个人资料。清理路径取自当前配置及既有默认值，并从只读数据库补充知识库绑定。停止服务前完成所有路径检查，清理前重新验证。拒绝危险根目录、符号链接根/祖先、与原文/配置/密钥/备份重叠的目标；清理树中发现备份目录、备份扩展名或加密备份文件头时拒绝，不追随内部符号链接。

本次实现和测试仅使用临时夹具，不执行当前真实安装的卸载。数据库与密钥保留是实现选择，目的在于维持可恢复性。
