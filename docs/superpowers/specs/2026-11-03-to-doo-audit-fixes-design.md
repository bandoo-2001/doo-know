# ToDoo 全页审查修复设计

## 授权与目标

用户已审阅本会话的 G/T/B/C/F/H/A/R/N/S/W 问题清单，并明确要求“行，帮我处理吧”。本轮直接落实该清单，保留现有蓝灰色工作台、Vue 与 Ant Design 控件。实现选择由代理负责，不重复要求确认；不部署、不操作真实数据、不推送或合并共享分支。

## Approaches

1. 仅调整 CSS：不能解决日期、上下文、导入确认等已确认行为问题，覆盖不足。
2. 在现有组件内修复行为并统一交互：本轮采用。尽量复用现有数据模型、校验、草稿和安全恢复机制，增加少量明确的摘要及选择入口。
3. 重做设计系统和业务模型：本轮无必要；迁移与兼容成本高。

## 全局约束

- 沿用 Vue 3、Ant Design Vue、现有主题变量；不新增依赖，不改持久数据格式，不做数据迁移。
- 保留现有深链接、任务范围、分页、草稿、导入版本核对、冲突处理、恢复和权限边界。
- 只用现有隔离测试夹具；浏览器服务串行运行，端口使用 4279/4280，真实服务及数据不变。
- 行为修复先有能失败的测试；可逆的纯样式调整用真实截图和现有交互测试验证，不添加镜像 CSS 常量的测试。
- 每一项清单须有修复、验证或明确的证据裁定；不把隐藏功能、固定日期、UTC、稀疏数据和首屏截取当缺陷。
- 新文案使用中文，说明真实状态和操作影响；不承诺不存在的自动保存或整体回滚。

## 设计决定

### 设置与导入（S1–S7）

导入预览绑定完整输入快照；任一解析参数或正文变化立即撤销确认资格。预览以分页或展开显示全部条目，包含日期、类型和目标位置。确认重试复用请求身份，发现已有导入作业后可继续读取。保存偏好仅在偏好分栏出现。修改显示时区时，同步原先跟随该时区的免打扰设置；显式展示免打扰实际时区。提供可搜索的时区建议，保留手填及校验。设置所有输入草稿纳入离开检查。原生文件选择以中文入口包装，应用生成的导入警告做结构化中文呈现。

### 任务导航与上下文（G1–G2、T1–T8、B1–B4）

保留现有路由，任务列表/看板/四象限/时间线切换共享范围且始终显示范围摘要；选择范围不强制切回列表。四象限继续兼容顶级深链接，但显示一致的任务上下文导航；时间线清楚显示任务视图及当前范围。手机更多导航固定名称。总览今日与任务今日使用同一个日期判定；当日新增与列内新增显式继承日期、清单、状态、标签、优先级。待办排除取消/跳过并显示终态。目标数字解释为叶子行动执行次数。手机工具栏压缩成主要操作和可展开管理；日期置于可读的位置。手机看板/象限提供列/区跳转和数量摘要。象限有直接设置入口、手动覆盖标识及恢复自动判断。

### 日历与时间线（C1–C13）

短事件最小可读高度与真实时长提示兼顾，完整标题/时间可读；跨月格区分；手机外部事件显示起止与时长。手机保留议程，并提供明确的网格展示选择，网格有最小宽度和横向滚动。时间线使用可横向滚动的最小日宽和固定标题列，截止显示日期时刻，区间外安排准确标注。统一显示时区换算；普通跨日块分段；时间线按实际区间重叠裁切，全天跨度用 dateEndExclusive；重叠事件按局部冲突组分列。所有新安排入口采用默认时长。逾期统一按实际截止时刻计算，全日截止保留原规则。

### 专注（F1–F7及轮询风险）

趋势与记录分区可折叠，手机默认突出当前操作，保留全部记录可达。未来桶不作为零值连接。计时项目与历史筛选分别命名，项目选择和“查看累计”采用不同动作；提供自由专注。记录显示人工修正标识；趋势、统计、历史各自显示范围。活动轮询能合并新纪录、移除已删除项并更新分页，不能伪称全部载入；保留已加载旧页。切项目时显式说明关联行动仍保留或允许清空。

### 习惯与纪念日（H1–H3、A1–A3、W5）

手机习惯卡紧凑排列；历史计量显示真实量与目标，补记时显示已累计量。提供当天条目列表与单条撤销，保留整天撤销的确认。按习惯实际时区提示记录日期。纪念日桌面限制单卡宽度；当天显示“就是今天”，过去一次性事件显示原日期；农历使用年/月/日控件和闰月选择，保存格式保持不变。

### 通知与统计（N1–N4、R1–R2）

通知动作写“确认提醒”并说明不自动完成事项；任务、习惯、纪念日均可查看来源。稍后选项与弹卡一致；增加撤销处理/忽略、恢复未读的受控路径。复盘历史完成数保留归档任务的已完成记录，当前待办/目标分母仍排除归档；为统计口径添加说明。零值使用明确的零，不伪装成正柱。

### 编辑窗口（W1–W4、W6）

新任务可直接设置优先级、提醒和重复；计划日期不会暗中附带未展示时刻，默认时长显式摘要。详情明确哪些操作立即生效、哪些需保存；关闭明确保留草稿或提示放弃，文案交代保留范围。成果笔记提供 Markdown 预览，沿用平台安全渲染。保留焦点与关闭按钮，修复手机键盘/底栏影响但不把首屏截断当遮挡。

## 验证与交付

补充上下文继承、预览失效、跨日/时区、局部重叠、归档历史、通知纠正、习惯单条更正等行为回归。运行相关浏览器回归、全量单元测试、类型检查、生产构建。使用固定时间和相同示例数据，保存桌面/手机、深浅色与主要操作窗口的真实截图及对比索引。待验证风险逐项核实；最后提交问题编号到结果的覆盖记录。
