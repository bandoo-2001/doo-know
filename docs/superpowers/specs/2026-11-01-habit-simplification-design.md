# 习惯交互简化

用户已确认按本次对比分析实施，并明确要求与其他 ToDoo 页面的 UI 统一。

沿用现有侧栏、页面标题、工具栏、卡片、Ant Design 控件、弹窗、主题变量和响应式布局。只调整习惯场景的信息层次和行为，不改其他页面的视觉骨架。

## 行为

- 新建默认为普通打卡；定量目标才显示数量和单位。旧习惯缺少目标类型时继续按定量累计处理。
- 频率明确区分每天、指定星期、每周累计、每月累计和每隔 N 天。指定星期与间隔是实际生效的规则；周/月累计保持既有语义。
- 普通打卡一天一次，重复操作不重复计数。周/月普通打卡以有记录的天数累计。定量记录明确表示本次新增，不把当天总量当作新增量。
- 开始日期、提醒在主表单；说明、结束日期、关联目标、资料和规则细节折叠。普通提醒直接选时间，既有复杂提醒保留且可编辑。
- 卡片使用简短频率摘要、可选常见图标和明确的主操作。已完成的普通习惯显示完成状态；定量追加降低视觉权重。
- 历史日期格只保留主要入口，跳过、休息、撤销移入日期详情；今日与周/月累计明确区分。
- 目标类型、间隔与星期修改写入规则版本，历史记录仍按原规则计算；不迁移或重写既有数据。

## 方案与边界

采用用户确认的渐进简化方案：保留现有组件和样式，增加习惯专用表单与提醒组件。单纯隐藏字段不能解决数量和周期歧义；整体替换页面样式不符合用户的统一外观要求。

不增加依赖，不启停或部署常驻服务。仅在当前已有隔离工作区增量修改；保留任务开始时全部未提交改动，不自动提交这些混合变更。

## 验证

领域测试覆盖旧数量累计、普通打卡幂等、指定星期、跨月间隔、历史规则和提醒。浏览器测试覆盖新建、编辑、单击打卡、定量新增、历史修改、桌面/手机和浅色/深色无溢出。

## 实施验收

已完成。459 项 ToDoo 测试、24 项 MCP/领域集成测试通过；桌面与手机浏览器回归各 19 项通过，最终新增流程各 5 项通过（共 40 个不同用例）。类型检查与构建通过。已人工检查深浅色和 320 像素窄屏，保留现有页面骨架。独立评审发现的旧提醒标识兼容与普通打卡日期上限问题已通过回归测试修复。运行中的服务未部署更新。
