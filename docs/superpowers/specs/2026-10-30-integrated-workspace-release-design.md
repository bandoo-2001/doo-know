# 图谱导航与工作区整合发布

用户授权：补齐图谱统一菜单和草稿离开保护，整合 To Doo、统一历史版本及必要共享改动，验证通过后更新正式服务，保留其他会话内容。

沿用 Vue 3、Ant Design Vue、共享 WorkspaceMainMenu、现有导航 intent/草稿协议和原生发布管理器。以实际正式 rc.55 的干净发布源码为基础，复制已冻结开发快照中的授权功能闭包；图谱菜单注入与模型设置草稿保护由组件暴露的 hasUnsavedChanges/requestLeave 接入宿主。关闭确认复用已有弹层，取消保持原路由和输入，放弃后离开；刷新/关闭触发浏览器未保存提醒，忙碌与重复离开不得获得重复许可。

整合保留 To Doo 的 AntDV、主菜单、按需二级导航、位置记忆、任务来源与成果、统一历史保存记录/Git 提交及恢复保护。博客与图谱现有功能继承 rc.55。MCP 权限树、传输导入面板等独立会话改动不进入本次发布；所需 DirectoryTreeSelect 和 HTTP crypto 兼容改动进入。

方案取舍：直接在共享开发目录构建会混入并发编辑；从旧图谱树发布会丢掉正式博客。因此本次选择从实际正式源码建立独立候选，按冻结文件和校验清单整合，构建后固定提交与归档哈希。原开发文件在部署前后逐项校验；新修复如需同步回共享目录，只按原字节校验通过的路径增量回写，发现并发变化保留用户文件。

发布复用现有固定 Node 和检索运行包；插件版本内容保持不可变，生产已装插件及启用状态不改变。正式资料用应用支持的加密备份，并在隔离目录实际恢复；先在资料副本与最终安装包验证，再通过原生 upgrade/update 切换新版本。代码回退保留 rc.55，不以旧数据库覆盖接受的新写入。
