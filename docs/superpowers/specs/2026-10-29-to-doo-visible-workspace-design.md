# To Doo 可发现、紧凑且有明确颜色语义的工作空间

用户明确要求先学习成熟 Todo 产品，再直接优化并同步关联页面。本次在当前已隔离工作区继续，保留原有未提交工作；不更改正式部署、账号和用户任务。

## 研究与选择

- [Todoist 优先级](https://www.todoist.com/help/articles/set-a-priority-in-todoist-Wy82Jp)：高、中、低、无分别用红、橙、蓝、中性色，并始终保留文字。
- [Things Guide](https://culturedcode.com/things/guide/)：日常时间范围与项目组织稳定可达；适用到今天、近七天、清单的分组。
- [TickTick Beginner's Guide](https://help.ticktick.com/articles/7054286604315131904)：任务、日历、四象限、专注和习惯有明确的功能入口。
- 使用已安装的 Ant Design Vue 4.2.6；按需导入 Button、Drawer、Dropdown/Menu、Segmented、Select、Tag/Badge，避免更换全局样式系统。

考虑仅换皮、增加隐藏菜单以及展开分组工作空间三种方案，选择第三种：它直接解决功能不可发现，保留既有功能与路由。

## 设计决定

1. 桌面侧栏直接展示“我的待办”“计划与执行”“回顾与管理”和“我的清单”，所有现有模块可发现；移除默认折叠的更多功能。导航使用现有路由，清单继续独立分页。
2. 手机保留页面/清单选择器，新增明确的“功能导航”抽屉以及直接可见的常用功能入口；选择后关闭抽屉，仍走未保存内容保护。
3. 收紧页头、输入和工具栏间距，内容使用可用宽度；矩阵在适当宽度下占满可用高度，四个区域各自滚动。小屏纵向排列，不横向溢出。
4. 四象限红/橙/蓝/绿，搭配名称与“立即行动、安排计划、协调处理、留待以后”。空状态解释如何添加/归类，而非只有装饰性空白。保持现有重要/紧急计算和拖动保存，不将任务优先级与重要程度混为一谈。
5. 任务行、优先级看板、详情选择器的颜色一致，显示可读文字。四象限保留截止/计划信息；重要/紧急编辑可直接发现。
6. 核心视图切换和操作使用 AntDV 合适的组件，保留键盘操作、可访问名称和深色主题。避免为了组件替换重写复杂业务表单。

## 验收

桌面无需展开菜单即可进入所有功能；手机功能入口可达；任务录入、导航回退和草稿保护仍然工作；矩阵可辨色且保留文字；真实服务只读检查，演示截图使用隔离数据。运行相关单元、桌面/手机浏览器、类型检查、构建，报告实际结果和限制。
