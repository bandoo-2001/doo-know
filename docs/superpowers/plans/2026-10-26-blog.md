# Blog Application Implementation Plan

> **For agentic workers:** use subagent-driven development or native execution; user approved the design and autonomous implementation.

**Goal:** 原生博客应用、现有笔记手动发布、公开快照站点，以及MCP同步和业务缺陷修复。
**Architecture:** SQLite持久发布版本/资源，独立公开SSR路由，完整Apps工作台；MCP通过新BlogPort使用同一核心服务，公开发布独立授权。
**Tech Stack:** existingVue3/Fastify/SQLite/Markdown/Vitest/Playwright, no newheavy runtime dependencies.
**Spec:** docs/superpowers/specs/2026-10-26-blog-design.md
