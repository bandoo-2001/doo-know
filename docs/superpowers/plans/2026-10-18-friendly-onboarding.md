# 面向普通用户的首次设置实施计划

> 使用 superpowers:executing-plans 在当前会话顺序实施；完成后独立审查。

**目标：** 用户默认只填知识库名称即可开始使用；高级设置保留。

**设计依据：** 本会话已批准的方案：创建或接入资料、按用途介绍可选功能、进入工作区；不以 Git 代替备份；服务器与浏览器设备的区别明确。

**架构：** 复用原目录校验、事务绑定和运行时激活。新增仅主人可调用的受限目录浏览和新建接口。Vue 三步向导负责流程与错误反馈，插件仍复用正式设置组件。

**约束：** 不改用户现有部署和知识库；不自动下载模型或安装插件；不扩大允许路径，不接受隐藏目录/软链接，不覆盖已有目录。响应丢失后新建重试返回原回执。

## 重点风险

- 目录浏览不可暴露允许范围外/密钥/运行数据，修改与浏览均受登录和 Origin/CSRF 保护。
- 新建不能将已有资料视为空白目录，重复请求不得产生第二份目录。
- 网络失败、目录不可写、初始化失败应留在当前步骤并提供可操作说明。
- 刷新后继续未完成引导；可选功能失败不能阻止进入工作区。
- 手机页面不横向滚动，键盘操作、表单标签及状态提示可用。
