# Responsive tabbar implementation plan

**Goal:** 手机和平板竖屏使用底部常驻 tabbar，平板横屏和桌面使用左侧竖栏。

**Architecture:** 复用共享 WorkspaceMainMenu 的菜单定义及受保护导航回调，将唯一 WorkspaceFooter 移出折叠侧栏。底栏显示前四个主入口及“更多”；更多面板承载完整主菜单、应用设置和账户/返回入口。二级任务清单和日期目录保留现有行为。

**Tech stack:** Vue 3、现有 CSS、Playwright。

## Constraints and decisions

- 在现有隔离工作区修改，保留所有已有未提交内容，不进行提交或发布。
- 宽度 <=720px、<=960px 且高度 <=500px 的手机横屏、<=1100px 的竖屏，以及 <=1366px 的粗指针竖屏使用底栏。其他尺寸保留 60px 左栏。
- 底栏最多五项；更多功能的当前名称和选中态显示在第五项。所有切换继续经过现有未保存保护。
- 为内容和浮动提醒预留底栏与安全区高度；平板旋转关闭更多面板。
