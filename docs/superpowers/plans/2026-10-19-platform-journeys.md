# Platform Journeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Independent bounded fixes can be delegated; root integrates and verifies.

**Goal:** 完成设计中的平台用户链路优化、完整验证及正式新版本上线。

**Architecture:** 沿用 Vue 3/Ant Design、Fastify、SQLite 与独立可信插件。宿主提供启用前的 MCP 引导；插件只提供本机运行与调用事实。发布仍使用既有原生包与恢复工具。

**Tech Stack:** TypeScript, Vue 3, Ant Design Vue, Fastify, SQLite, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-10-19-platform-journeys-design.md

## Global Constraints

- 保护当前未提交工作，不自动改真实知识库；测试使用独立数据和端口。
- 不输出密钥；保留权限边界与默认只读。
- 不引入数据库格式变更；外部验证与模拟严格分开。
- 本次版本号按现有发行列表确定，禁止覆盖已发布版本。

## Review Focus

- 登录成功但状态请求断网：会话保留、页面可重试，不能空白。
- 修改模式及刷新插件状态：用户未保存输入不被覆盖，相关字段可理解。
- 本地端口可监听但通道未开：不能显示 ChatGPT 已连接。
- 切换 Git版本期间请求乱序/失败：差异和恢复对象不能错配。
- 公开最新发行低于本机：拒绝无意降级，回滚功能仍可用。
