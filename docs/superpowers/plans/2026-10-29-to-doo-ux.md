# To Doo UX Simplification Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans or superpowers:subagent-driven-development. Follow the tasks below without modifying unrelated work.

**Goal:** Reduce the effort needed to find, add and edit daily tasks.

**Architecture:** Keep the Vue workbench and backend. Promote common task filters to the workspace, reuse persisted task drafts for inline capture, and progressively disclose advanced UI.

**Tech Stack:** Vue 3, TypeScript, existing CSS, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-10-29-to-doo-ux-design.md

## Global Constraints

- Existing linked worktree; preserve unrelated uncommitted work.
- No new dependencies or production deployment; browser checks use isolated E2E fixture.
- Preserve task/occurrence semantics, draft recovery and idempotent retry.

## Review Focus

- Quick capture fails or returns an unknown result: input remains recoverable and cannot create duplicates.
- Switching clear/list/today filters: old date and archived filters must not leak.
- Quick capture inside a selected list: list and plan date must be retained.
- Collapsed detail fields: draft values remain mounted and saving preserves values.
- Narrow screens and dark theme: primary controls remain visible without horizontal overflow.

## Tasks

- [x] Add meaningful tests for quick filter transitions and inline creation context; implement shared presentation helpers.
- [x] Simplify workspace navigation, task toolbar, quick capture and task rows; integrate responsive styles.
- [x] Simplify task creation and editing through expandable groups, preserving explicit saving and draft guards.
- [x] Update existing browser interactions for intentional disclosure changes; add quick-capture, filter, failure-recovery and layout checks.
- [x] Run targeted Vitest, typecheck, build and desktop/mobile To Doo E2E; inspect screenshots and request independent code review.

## Execution Notes

Implementation is directly authorized by the user's request. Routine reversible design choices are resolved in the workspace. No extra approval gate or commit of unrelated files is needed.

Browser checks exposed an existing search query defect: matching task titles removed their execution context, so results disappeared in board view. Correct the task/occurrence/timeBlock query together, preserving list scope, pagination and literal search escaping. Keep search within task data and occurrence titles; do not implicitly search other permission domains.

Independent review also added regressions for dataset timezone on initial deep links, the identity of a new task draft when switching lists, and immediate sidebar refresh after deleting a list. The existing Workspace test harness required a mapping for the already-present app-shortcuts import; the production shortcut implementation was preserved.
