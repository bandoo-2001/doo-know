## 单元与接口

1. server/config.ts、db.ts、auth.ts、app.ts；tests/auth.test.ts：createApp(config)、createFixture、loginFixtureOwner；先验证匿名 401、登录、注册关闭、会话撤销。
2. server/files.ts、notes.ts、shared/contracts.ts；tests/notes.test.ts：NoteDocument、原子保存、mtimeNs 字符串、冲突重试；UI CodeMirror。
3. server/shares.ts、render.ts；tests/shares.test.ts：每次读取最新文件，撤销/重置失效、公开字段限制。
4. server/recovery.ts 与 folders；tests/recovery.test.ts：历史/回收站，恢复占用 409，失败保留原文。
5. server/assets.ts、search.ts、web/components；tests/search-assets.test.ts 与 Playwright：相对引用、逐次附件授权、桌面/手机两栏布局。
6. scripts/backup.ts、restore.ts、deploy 模板、README；完整测试、类型检查、生产构建、隔离恢复演练与截图对照。

## 接口预检

- 阶段一会话与 CSRF 请求头由阶段二至五复用。
- 阶段二 NoteDocument.modifiedAt 为 mtimeNs 十进制字符串，保存与历史恢复使用同一锁/比较逻辑。
- 阶段三分享通过 note ID 读取阶段二原文件，阶段四删除立即停用分享。
- 阶段五渲染和附件授权都使用 Markdown 解析的当前相对引用；访客不获取其他笔记 ID、路径或历史。
- 阶段六备份包含原文、数据库、历史，恢复撤销 session 与 share。
