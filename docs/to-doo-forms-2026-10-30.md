# To Doo 表单结构与样式精简

> 历史阶段记录；当前统一布局、实现状态与验收以[唯一规范入口](design/to-doo/unified-ui-v2/IMPLEMENTATION.md)为准。

2026-10-30，承接同日的缺陷排查，进一步减少表单填写负担与操作次数。保留此前全部未提交修复，沿用已有组件、数据和接口。

## 调整

| 表单 | 默认操作区 | 补充内容与处理 |
| --- | --- | --- |
| 清单 / 目标 | 名称、直接选择清单或目标；目标再显示目标日期 | 说明、成功标准、自动完成、资料按需展开；切换类型保留旧值 |
| 习惯 | 名称、周期、数量、单位；从约 12 项缩到 4 项 | 开始/结束、关联清单、跳过规则、时区、提醒与资料放到补充区；修改既有规则时直接显示生效日期 |
| 纪念日 | 名称、日期、历法、每年重复 | 农历才显示闰月；计数方式、分类、说明和闰日策略按需填写 |
| 时间安排 / 事件 | 标题、日期、时间及需要的时长 | 全天时隐藏时间与分钟，显示结束日期；关联任务显示摘要，时区与说明收进补充区 |
| 推进记录 / 成果 | 正文、已有完成标准与关联完成操作 | 投入时间、验证方式和资料放到补充区 |
| 批量编辑 | 按常用修改、内容与归属分组 | 勾选字段后才出现对应输入，避免大量禁用控件；底部操作保持可达 |
| 成果笔记 | 标题、正文及保存 | 目录和验证方式收进更多保存选项；任务归属、错误与继续恢复始终可见 |
| 偏好设置 | 日常使用、日期与提醒 | 任务规则和专注节奏独立展开，并显示当前值摘要 |
| 导入 | 先选择文件或粘贴内容 | 格式、去重、位置等在导入选项中；列映射为同级入口，确认与恢复流程保留 |
| 复盘 | 日期范围、简洁统计和写复盘入口 | 缩减装饰性统计卡片，保留真实统计、进度及明细 |

任务详情新增“重复 / 提醒 / 资料”三个摘要入口，一次点击直接展开并定位原有编辑区。快捷跳转跳过该次折叠动画，普通手动折叠仍保留动画。

样式统一到相同的分组、字段间距、说明和底部操作；补齐弹窗里的深色输入框、日期、勾选文字和按钮，检查 320px 布局。

## 数据与交互保护

- 隐藏字段继续保留草稿中的值，保存时不因收起而删除；原有 `null`、布尔值、数值零和多选标识的行为不变。
- 全天保存仅在提交副本中将时间设为空，切回定时仍保留本次输入；新习惯的首次规则生效日期跟随所选开始日期。
- 收起区域中有必填错误时，保存会展开并聚焦错误输入，显示提示。
- 仅修改模板任务行或“同时完成关联行动”也纳入未保存检查，取消放弃确认时保留输入。
- 本轮没有更改服务端实体格式、安装依赖或操作真实数据，也没有部署。
