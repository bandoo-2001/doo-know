# 知识图谱

从“应用 → 知识图谱”进入。知识图谱会随资料变化在后台更新，支持从正文发现概念、追溯关系证据、整理实体和基于原文提问。原始 Markdown 不会被自动改写，也不要求先手动添加所有笔记链接。

## 关系来源

| 来源 | 能做什么 | 如何理解 |
| --- | --- | --- |
| 笔记引用 | 读取 Markdown/Wiki 显式链接，显示入链、出链与孤立项 | 用户在原文中写下的引用 |
| 基础本地分析 | 从标题、标签、别名与正文提取词项、概念及句内共现 | 无须模型；共现仅是探索线索 |
| 向量语义相似 | 复用搜索索引的 BGE 文档向量，比较笔记内容 | 真正的向量余弦分数，不依赖词项重合；属于相关资料线索 |
| 模型增强 | 提取人物、组织、地点、事件、技术实体及带名称的关系 | 必须关联真实原文摘录；关系先作为候选，可确认、编辑或忽略 |

相似分数或模型置信分用于排序和筛选，不代表事实正确的概率。基础关系、模型建议和人工确认会分别呈现，不能仅凭一条连线认定因果或依赖。

## 向量语义相似

在“筛选”中开启“显示语义相似（向量）”，可以调整最低余弦相似度，默认 0.65。它复用“设置 → 搜索与索引”中已有模型产生的有效分块向量，不另行下载模型、不重复请求嵌入，也不要求配置图谱对话模型。已发布的有效向量在模型服务离线时仍可使用。

每篇笔记按分块覆盖的非重叠字节数加权，再归一化为笔记向量。比较时从授权笔记中查找余弦分数最高的少量邻居，而非先靠相同词项缩小候选。每条连线保留两端的实际索引片段和行号，可回原文核对。相似度与模型关系置信度分别筛选。

缺少向量、索引尚未完成、来源发生变化或向量损坏的笔记不生成相似边；页面显示索引状态，不退回词项重合算法。切换模型空间后，等待对应索引完成才参与比较。大库按预算比较有限候选，并明确标记有限子图；选择起点可优先探索指定笔记。

当前每次最多检查 2,048 篇候选元数据、读取 32,768 个分块向量，默认选择最多 32 个探索起点，每个节点最多三条相似边。超过候选、读取、比较或时间预算会标记部分结果；状态数量也属于本次有限范围。指定起点优先加载，即使它不在默认候选页中。

## 配置本地模型或模型 API

打开“更多 → 模型设置”。默认选择“基础本地分析”，不访问模型网络服务。

**Ollama：**选择 Ollama，填写从 DooKnow 服务器可以访问的地址，例如 `http://127.0.0.1:11434`，以及该服务中已经安装的模型名称。这里的 `127.0.0.1` 指运行 DooKnow 的机器，不是浏览器所在的电脑。应用不自动下载模型权重。

**OpenAI 兼容 API：**填写兼容服务的基础地址，例如 `https://api.example.com/v1`、模型名称，以及需要时的 API 密钥。地址应为基础地址，不含 `/chat/completions`；Ollama 地址不含 `/api/chat`。

向非本机服务发送正文前，需要在设置中勾选明确许可。测试连接使用合成文本，不发送真实笔记。明文 HTTP 只接受本机地址或 Ollama 的私网 IP；外部服务使用 HTTPS，URL 不接受账号密码、查询串或跳转。

先保存，再测试已保存连接。高级参数可选择 JSON Schema 或 JSON 模式；部分兼容服务只支持后者，两种模式都会在本机严格验证输出。可调整每次输入字符和超时预算，仍受模型服务自身的上下文限制。

API 密钥只留本机加密配置，不回传页面、不进入知识库 `_data` 或 Git，也不会出现在导出和普通错误消息中。变更提供方或服务地址时，旧密钥不会自动转交新地址。模型配置是本机状态；只迁移知识库时需重新配置，完整加密备份沿用宿主密钥恢复链。

## 自动更新与后台任务

知识库运行时会启动图谱后台分析，无须先打开图谱页面。保存、创建、移动、删除、恢复和宿主检测到的外部修改都会触发更新。未启用宿主检索时，图谱仍有分批文件发现与变更补偿，不依赖 Python、向量模型或全文索引就绪。

工具栏的状态胶囊只展示简短状态，点击可以查看完成/待处理/失败数量，并暂停、继续、重试失败、重建或取消任务。关闭“自动分析”保留仍有效的已有结果，新资料变更等待再次开启或一次显式重建；取消任务会暂停，不删除笔记和人工决定。

后台任务持久保存，服务恢复后会检查租约与来源版本。文件在模型处理期间改变，旧结果不能重新发布；源文件删除或变得不可读后，旧证据也不继续展示。页面开启时自动检查变化，隐藏标签页和离开应用后会停止页面轮询。

## 保持画面简洁地探索

默认显示工具栏和有限的知识子图。切换到“笔记”可浏览原有引用关系；“画布”和“列表”互斥，列表也支持键盘浏览。

图谱界面沿用项目已有的 Ant Design Vue 主题与组件。工具栏使用分段切换和搜索框；视图、问答和模型设置收在“更多”中。桌面直接显示审核入口，手机通过“更多 → 关系审核”进入。弹窗、抽屉、表单、列表和详情卡均采用 AntDV 组件。

- 搜索名称、相对路径或人工别名，英文字母忽略大小写。
- 在“筛选”中设置目录、节点类型、关系类型、置信分及孤立项。
- 待审核模型候选和向量语义相似默认关闭；相似开关独立于候选开关。
- 点选节点或边后才显示详情。桌面使用可关闭侧栏，手机使用抽屉。
- 在详情中展开一至两跳；路径功能选择起点和终点。人工关系也参与局部探索。
- 类型和关系分组用于着色；分组是拓扑上的连接分组，不是模型已证实的主题分类。
- 默认最多 80 个节点、120 条显示边；范围超过展示预算时，提示当前子图和范围总计。已有节点尽量保留位置、缩放与平移。

共现和相似边没有方向箭头。引用、提及、语义和人工关系保留其方向。边的名称在选中后显示，避免整张图铺满文字。

## 证据与人工整理

详情和审核面板显示来源笔记、原文摘录、行号以及本地分析/模型提取/向量索引/人工关系的来源标记。点选证据可以打开原文对应行。相似边的片段用于查看比较内容，不等于事实关系证据。

在“审核”中确认、改写或忽略候选关系；支持状态、关键词搜索和分页加载。忽略记录会保留，重建不会让已忽略关系重新冒出；可以在“已忽略”中恢复候选。

实体详情可新增别名、合并重复实体、添加以笔记为依据的人工关系。合并与别名不改写原文。笔记之间的正式引用仍通过原文链接表达。

人工状态使用版本检查和请求身份；未知结果重试会复用同一请求，避免重复创建视图或关系。外部同步产生冲突时保留材料并要求核对，不用缓存覆盖知识库中的人工决定。

## 问答、视图与导出

“问答”使用所选节点或问题命中的有限原文证据。需要先配置模型；模型只能引用本次提供的有效来源，资料变化后会要求重新提问。没有足够证据时应保留不确定性。

“视图”可保存筛选和探索范围，之后直接恢复；还可下载当前授权图谱 JSON 或画布 PNG。导出当前图不能替代整库备份。问答的证据和人工分析也不能替代原文。

## 数据、权限与边界

自动分析、索引、任务和模型配置留在实例运行数据库；可重建的自动结果不会写回正文。人工确认、忽略、合并、别名和保存视图位于 `_data/apps/knowledge-graph/state.json`，应随原文一起迁移、同步和备份。该文件不包含模型密钥。

接口需要主人登录，不向公开分享暴露完整图谱。核心服务先过滤获准来源，再聚合实体属性、证据、关系和统计；没有来源锚点的主人注释仅向主人显示。

分析遵守平台 20 MiB 文件上限、最多 256 分块及单任务时间预算；每篇的实体、关系和证据也有上限。超出预算会报告部分结果或失败，不把省略当作完整。图查询最多加载 512 份相关来源、16 MiB 派生 JSON，并有节点/边上限；搜索和局部中心有索引定位，不会固定只搜索知识库最早的资料。

模型协议通过受控合成服务验证。实际本地模型或远端服务的连通性、结构化能力和抽取质量，需要在用户配置后测试。

## 隔离开发

源码位于独立 worktree 和 `codex/knowledge-graph` 分支，不直接编辑其他会话目录。开发实例分别设置 `DOOKNOW_DEMO_ROOT`、`PORT`、`VITE_PORT`、`APP_ORIGIN`；已有显式原文、数据和密钥路径也应独立。

浏览器测试通过 `DOOKNOW_E2E_WEB_PORT`/`DOOKNOW_E2E_API_PORT` 选择独立端口。知识图谱协议验收用 `DOOKNOW_E2E_GRAPH_MODEL=1` 启动仅提供合成资料的本地 fixture，不调用真实模型。其他历史用例若写死了来源地址，仍需串行或单独适配。
