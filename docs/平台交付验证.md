## 真实迁移与接入

原文改名先沿用旧固定发行版本，停写并验证完整加密备份后，同文件系统移动，按原字符串、真实路径、设备号和 inode 比较更新根身份，确认恰好一行。旧版本重新验收后，才另行备份并接管至新平台。原有账号、21 篇笔记身份、历史关系与旧操作回执保持连续；交付文档随后通过实际 MCP 新建。

真实 ChatGPT/Codex 已连接的 Tunnel 已切至官方 MCP：匿名拒绝、15 个工具、原笔记读取、旧请求回执与索引状态通过；实际创建 B、更新 C、重试原创建 B 返回固定 B 回执，读取仍为 C。调用记录仅包含工具及结果等元数据。
