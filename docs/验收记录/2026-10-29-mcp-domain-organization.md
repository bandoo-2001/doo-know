## 使用方式与交付能力

宿主插件 API 为 **1.2.0**；MCP 插件 **1.2.0** 要求宿主 API `^1.2.0`。旧 KnowledgePort 方法保持兼容，新增组织服务及本人权限 context 服务均为可选接口。

MCP 设置按业务域分卡片，分别选择能力与资源范围：

- 知识库：只读、内容编辑、自主整理；范围为整个知识库，或稳定 ID 绑定的笔记/目录。归档与手动索引维护单独授予。
- 博客：读取与公开发布独立于知识库写入。发布原文只需相应读取权限；公开发布仍需明确的发布意图。
- 待办：注册表预留独立域，目前不启用待办业务或工具，不因其他域授权而自动获得权限。

选择知识库“自主整理＋整个知识库”并完成客户端一次授权后，Agent 可以自行了解最新目录、创建目录和笔记、移动和重命名笔记及目录。以后新建的普通顶层目录自动纳入 all 范围，日常操作没有逐次审批步骤。

插件策略是上限，客户端拥有独立授权。收窄上限实时限制后续调用；扩大上限不扩大旧客户端授权。OAuth 扩权需要一次重新授权；Tunnel 提供明确的授权操作，轮换密钥本身不恢复被撤销的 grant。

## MCP 与执行流程

工具总数为 **23**，新增：

- `get_mcp_context`：调用者自身有效分域权限及知识库结构上下文。
- `list_directories`：分页展开目录，包含空目录和可操作标记。
- `organize_library`：创建目录、移动/改名笔记、移动/改名目录。
- `list_organization_history`：当前仍有权查看的本客户端整理历史。
- `undo_organization`：版本及权限核对后的补偿任务。

`create_note` 支持目录 ID；`directoryId:null` 明确表示业务根目录。旧 directory 路径输入继续支持，两者同时提供时必须匹配当前路径。移动保留 noteId、directoryId 与 assetId。

写入使用原 requestId 去重。accepted 表示后台任务已接受；查询 operation_status 的 succeeded 才表示完成。文件整理完成与索引完成分别报告。任务结果未知时查询原请求，不用新 ID 重复写入。

任务在准备后和暂存后分别核对当前授权、完整正文/目录覆盖及引用版本，提交期间持有独占 gate。网页、MCP 和旧 Agent 的异步知识读取持有共享租约至读取或响应完成。

## 数据完整性与恢复

引用改写保持非引用原文不变，覆盖 Markdown 链接、图片、引用式链接、Wiki 链接和白板链接，保留 query、fragment、编码及格式。代码示例、数学内容和外部/稳定 ID 链接不改写。移动单笔记默认重算附件相对路径；目录移动包括受管理附件及外部入链。

文件系统操作采用持久化 journal、修改前材料、对象证据和排他发布，支持 dataRoot 与 knowledgeRoot 位于不同文件系统。启动先恢复未完成整理，再开放扫描和索引，避免把部分移动结果导入成新笔记身份。

无法证明的对象发布或外部冲突保留原件和恢复证据，进入 needs_reconciliation 并阻止普通读写。维护页显示整理状态与操作编号，摘要不返回正文或私有路径；不会误报没有待核对任务。

撤销检查后续内容、目录成员、原路径占用及新入链，不覆盖后续修改。材料在 dataRoot/organization 保存，默认保留 30 天；维护页高级设置可选 1–3650 天，仅影响将来的整理任务。未完成或核对中的材料不按期限清理。

备份包含整理材料；经校验的恢复保留目录身份并重新绑定磁盘证据，撤销材料仅在输出内容与成员一致时继续有效。恢复会撤销旧远程授权。博客实例 ID 在恢复时保留，避免策略失去所属站点。

离线同 inode 根目录改名会同步组织绑定版本和已完成 journal；存在未完成任务时拒绝迁移。验证包含实际“移动笔记→离线改根名→撤销”往返。

## 安全与兼容决策

稳定目录身份跟随改名；旧路径上新建的替代目录不会继承原授权。旧机器策略、短期 Agent 断言、OAuth 与 Tunnel 都执行资源边界。所有路径仍限制在本知识库业务资源内，不提供任意文件或命令执行。

旧版 OAuth consent 仅在插件仍为 v1 配置时保留兼容语义；配置迁移到 v2 后拒绝旧形状授权。旧连接不自动得到 organize、all、待办或新的博客能力。缺失的旧选区不会自动绑定后来出现的无关对象。

外部编辑器对同一路径笔记的原子保存延续既有逻辑笔记版本语义；目录同路径对象替换则创建新身份。无法从 inode 变化独自推断用户是否意图创建一篇无关的新笔记。

默认分类只用于初始化，普通顶层目录可以动态组织。业务根、90-Archive/99-System 运行容器、隐藏运行数据及保留文件名继续受保护。整理不会隐含合并目录、归档、永久删除或公开发布。

完成回执、目录页及历史页按完整 MCP JSON-RPC 帧测量，计入转义路径与请求 ID，并为最不利 RPC ID 预留空间；整理和撤销在写入前拒绝不可返回的完成回执。真实合法长路径用例已验证拒绝前没有移动任何源文件。

单任务预算为 50 个显式动作、1,000 个文件、2,000 个目录、128 MiB 正文与 512 MiB 附件。超预算或不支持的引用在写入前拒绝，由 Agent 重新规划。工具发现完整帧已按最不利转义 ID 测量为 **65,441 字节**，仍需在后续扩展 schema 时重新检查 65,536 字节上限。
