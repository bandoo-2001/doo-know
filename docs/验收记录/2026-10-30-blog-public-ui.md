# 公开博客界面验收（2026-10-30）

本次从正式 rc.53 隔离开发，只调整公开渲染器、样式、自托管阅读脚本、对应测试与文档，不引入依赖、数据库迁移或发布模型变更。

## 界面

- 共用页头、导航与页脚重新整理；保留三套主题、个人资料、配色、字体、内容宽度、卡片和模块顺序。
- 文字博客以文章流为主，卡片杂志突出封面和精选，个人主页保留资料侧栏；手机自动切换单栏，导航换行且可直接操作。
- 文章增加面包屑、作者与元信息层级、适宜阅读的正文宽度、桌面独立目录和手机原生折叠目录。
- 增加阅读进度、当前目录提示和原生返回顶部；保留复制、分享、专题上下篇与继续阅读。无脚本时正文、目录及链接可正常使用。
- 正文源标题与快照 HTML 不变；代码和宽表格在自身区域滚动。管理端草稿预览与公开端使用同一渲染器。

- 阅读、核心、接口与安全 4 文件44项通过；装修、便携数据与发布核对3文件26项通过，共70项。

- 独立代码审查及间距修正复核通过，无未关闭问题。
- 原测试随结构更新标题选择器；头像上传等待实际返回的 previewUrl，避免把旧头像当作本次上传结果。
