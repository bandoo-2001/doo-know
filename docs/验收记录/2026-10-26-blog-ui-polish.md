# 博客页面细节优化验收

本轮沿用博客原有风格与手动发布方式，优化工作台、公开页和手机操作，并修复验证过程中确认的既有文件监听竞态。

## 页面改进

- 文章首次读取有明确加载、失败与重试入口；较早请求不能清除较新读取状态，正文与源哈希仍由完整读取一并更新。
- 搜索／筛选无结果提供重置；文章信息改用中文说明，封面、置顶与固定链接放入可折叠的次要设置。
- 保存、预览与发布集中于操作栏；手机输入字号至少 16px、主要按钮至少 44px，改进长文字换行与间距。
- 下架／移除确认默认聚焦取消，支持 Tab、Escape、关闭后归还焦点，切换文章会取消旧确认。
- 公开页跟随系统深浅外观，显式浅色设置优先；调整标题／正文层级、目录、段落与代码表格，保留原始正文标题和发布快照。
- 公开筛选有选中、重置和不同空态；补充主导航、当前页、键盘焦点和跳过导航入口，代码／表格保留内部横向滚动。

## 监听问题修复

真实临时文件／HTTP／SQLite 探针确认，集合监听在异步 stat 与读取之间遇到临时 EACCES 时，会把原稿标为 inactive，触发博客下架；因此权限恢复后仍返回 404。这是本轮之前已有的竞态。

`collections/service.ts` 仅补充错误分类：权限、I/O 等非缺失错误保留源身份，确认 ENOENT／ENOTDIR 或无效源继续按原规则处理。新增两项真实监听回归，覆盖临时权限恢复和实际删除。未关闭监听、增加生产权限或改变发布授权。
