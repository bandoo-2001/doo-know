用户明确要求补齐 MCP 的全部现有知识库、博客和待办业务能力。本次保留原有 32 个工具，增加 38 个知识库工具、16 个博客工具、20 个待办工具和 4 个共享传输工具，共 **110 个工具**。宿主插件 API 与 MCP 插件版本为 1.3.0。

## 覆盖与使用

- [完整功能和权限说明](../MCP完整功能与权限.md)
- [知识库逐项覆盖表](../mcp-knowledge-coverage.md)：历史、目录与回收站、集合、反向链接、附件、图形和白板、文档和整库资料包、分享、维护与操作恢复。
- [博客逐项覆盖表](../mcp-blog-coverage.md)：查询、分类标签、草稿、站点设置、删除、不可变版本与封面资源、图块与带图发布。
- [待办逐项覆盖表](../mcp-to-doo-coverage.md)：25 种实体、18 种命令、任务计划与全部执行领域、导入导出、附件、日历订阅、提醒设备、成果笔记和操作恢复。

新授权动作与旧连接分开：`knowledge:share/manage`、`blog:write/manage`、`to-doo:share/integrations` 均需明确授予。公开编辑分享还需资料写权限。数据集变更后，主人可显式重新绑定当前数据并重新选权；查看设置不修改授权，确认页和收窄页面不能借此扩大权限。

大内容通过绑定调用主体、客户端、知识库、资源和版本的传输会话处理。顺序追加、相同字节重试、哈希、长度、最终请求占用、权限复核、配额释放、定期过期清理和受控目录检查均有覆盖。整文件下载链接要求主人登录，不含访问令牌或服务器路径。正文与分块下载共享读取速率。

HTTP 取消通知会定位原认证主体、客户端和请求的控制器。业务写入继续保留回执与未知结果查询语义；取消不声称回滚已提交内容。观察日志只记录已知工具与安全元数据。
