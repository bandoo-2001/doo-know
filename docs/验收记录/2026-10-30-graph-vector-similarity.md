# 知识图谱向量语义相似验收

日期：2026-10-30（Asia/Shanghai）。基线：`8126d74`。独立 `codex/knowledge-graph` worktree，仅修改源码与合成测试资料；未部署，未改实际知识库与现有运行服务，未下载模型或安装依赖。

## 实现范围

- 删除图谱相似边的词项 Jaccard 分支，复用现有已发布 BGE 文档向量缓存。
- 分块按非重叠字节覆盖加权聚合，再归一化计算笔记间余弦；不使用 query 编码或词项候选限定。
- 当前来源、嵌入空间、发布代次、分块与缓存须一致，来源或索引变化后旧结果不可返回。
- 结果保留两侧原文片段和行号，向量不就绪明确显示状态；相似分数独立于关系置信度。
- Ant Design Vue 筛选按需显示独立阈值，默认 0.65；沿用 80 节点、120 边的界面限制。

## 真实模型语料

使用本机已有 Python 环境与 BGE 权重，以参数传入测试，不写入正式应用配置。测试启动独立临时向量运行时，使用三篇合成中文资料，调用真实 `/embed/documents`，经现有 `FlatFileStore` 发布后查询完整图谱。

| 配对 | 真实 BGE 余弦 |
| --- | --- |
| 家庭照片备份与不同表述的相同操作 | 0.7671247 |
| 原始备份说明与番茄炒蛋食谱 | 0.4556465 |
| 改写备份说明与番茄炒蛋食谱 | 0.3854687 |

阈值 0.65 和正负样本至少相差 0.15 的断言在测量前固定。这组语料证明真实模型接入和具体改写能力，不代表对所有知识领域的检索质量评测。
