# 博客综合升级验收记录

后续：三项测试异常已修复，新版于 2026-10-30 部署到正式服务 rc.52；参见[测试修复与正式部署](2026-10-30-blog-production-rollout.md)。下文保留首次开发验收时的准确状态。

用户授权按推荐方案直接综合开发，覆盖主页装修、发文与阅读体验、专题与知识引用诊断。实现沿用单主人、单站点、手动发布快照模式；原稿编辑不会自动替换公开内容。

## 已实现

- 「应用 → 博客 → 装修主页」：文字博客、卡片杂志、个人主页三套不同布局；主题色、字体、宽度、卡片样式；姓名、介绍、头像及横幅裁切上传。
- 个人介绍、精选、最近更新、专题、项目、友链六类模块的添加、排序、隐藏、删除、标题及数量设置；自定义站点导航和社交链接。
- 装修草稿、真实页面实时预览、电脑／手机宽度、显式发布、最近十次发布历史及恢复到草稿。保存或预览不公开草稿媒体。
- 专题名称、路径、介绍及文章阅读顺序；公开端只显示当前已发布文章，撤下后及时退出专题和推荐。
- `/blog/-/articles` 搜索筛选和分页，`/blog/-/collections` 专题；安全 Markdown 关于页、阅读时间、目录、上下篇、相关文章、代码复制、链接分享、封面分享元数据及结构化信息。
- 首次公开前修改文章路径；原稿附件封面选择、上传和裁切；线上／待发版本对照、引用诊断及关联文章提醒。
- 七个 MCP 装修工具；完整配置按 UTF-8 字节分页，大 JSON 和媒体使用原有分块传输。站点查看、管理和发布分别授权，旧凭据不自动扩权。
- 新增装修 SQLite 表和独立 `_data/apps/blog/design.json`、`design-media/` 便携数据；保留原有 `state.json` 格式。换机重建、图片校验、备份恢复及恢复后默认关闭博客均有回归覆盖。

## 重点修正

独立审查与实际浏览器验收发现并修复：双设备相同计数同步后误接受旧发布确认；目录／指定文章权限外的目标发布状态和链接泄漏；历史 `articles`、`collections` 地址冲突及旧文章无法重发；搜索笔记后附件封面路径计算错误；异步图片完成写入其他文章；站点关闭时快照图片预览失败；头像上传的 multipart／JSON 契约不一致。每项有针对原行为的回归验证。

新发现页使用 `/blog/-/…` 避免占用合法历史文章 slug；旧 `/blog/articles`、`/blog/collections` 在已有公开文章时优先保留文章，未占用时仍可作为发现页别名。关闭／下架不依赖长时间公共缓存。

## 验证

- 初始博客基线：5 个文件、59 项测试通过。
- 集成博客、MCP 与便携数据：19 个文件、156 项测试通过。
- 最后权限、同步和上传修正后的定向验证：5 个文件、48 项测试通过。
- 全部博客相关与 MCP 错误契约在最终稳定代码上重新验证：19 个文件、159 项测试通过，退出 0。
- `npm run typecheck`：通过。
- `npm run build`：通过，包含前端构建、服务端 NodeNext 编译和本机进程运行器产物复制。
- 电脑／手机实际浏览器覆盖新装修到公开访问、头像裁切上传、草稿不公开、模块排序、项目、专题顺序、历史恢复、三套主题、公开搜索分页、私有草稿隔离、剪贴板复制及发布前正文对照。
- 原有博客浏览器回归覆盖手动发布、原稿隔离、异步文章切换、版本冲突、失败重试、确认焦点、系统明暗与长内容阅读。原测试中“文章列表重置回首页”的 URL 断言随首页／文章列表分离更新为新文章列表地址；行为断言继续保留。
- 18 项独立电脑／手机浏览器场景均已通过：完整四文件回归中 16 项先通过，文章列表新地址断言修正后对应 4 项阅读回归通过；新增 4 项装修／阅读场景再次在最后构建上通过。桌面预览 iframe 实际宽度 1100px、手机 375px，并按宿主宽度缩放，不把窄面板当作桌面断点。

浏览器默认端口被其他并行任务使用，本轮在独立临时源码／构建副本和 4187 端口运行；只替换测试配置与夹具中的测试端口，未改产品端口。新功能最终截图保存在 `logs.local/blog-studio-showcase-20261029/`，完整浏览器输出在 `.superpowers/sdd/2026-10-29-blog-studio/`。

额外的全项目 `npm test` 未取得全绿结果：并行运行期间出现 `git-process-recovery`、`git-containment-failure`、`e2e-server-lifecycle` 三项失败，随后主动停止本轮额外检查（退出 130），保留日志。此时另一个全量测试进程也在同一工作区运行。

独立调查没有修改这些测试或业务源码：Git 崩溃恢复单独复跑通过；推送隔离测试复现了整个测试 30 秒预算耗尽，其三个顺序操作各允许 15 秒；保留业务断言、只将命令行总预算设为 60 秒后复跑通过，实际耗时约 12 秒。崩溃恢复和生命周期夹具还分别使用固定 15183／4179 端口；生命周期就绪探测无法区分端口上的另一个测试进程。上述端口竞争与高负载是有代码和进程证据支持的干扰路径，但原始失败的完整堆栈未输出，因此不宣称已确定或修复全部全量失败。博客专项与独立端口浏览器验收结果单独成立。

## 范围及实际限制

公开搜索覆盖已发布标题、摘要、分类和标签；不建立正文全文索引。引用检查每篇最多返回 100 项提示和 50 篇关联，反向关联检查最近 300 篇公开文章。媒体当前保守保留，尚无未引用图片自动清理；公开分类统计仍有可进一步优化的多页重复扫描，未宣称完成大规模压测。

保护既有与并行产生的用户改动。没有新增本任务运行依赖，没有提交或推送 Git、生成发行版、重启正式服务、开启正式博客或修改正式知识库。
