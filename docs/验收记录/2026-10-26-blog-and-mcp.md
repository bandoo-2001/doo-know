# 博客应用与 MCP 验收

实现：应用 → 博客，从现有 Markdown 选稿，独立编辑文章信息，预览后显式发布。原稿修改保持私有，手动「发布更新」后才改变公开快照。包含分类、标签、置顶、封面、站点设置、公开文章、归档、关于、RSS、sitemap；支持桌面、手机与深色界面。

MCP 插件升级为 1.1.0，Host API 为 1.1.0，增加状态、发布、下架工具和独立 `blog:publish` 授权。默认禁用发布，旧授权不扩权。已有分享期限及编辑权限保持独立。

## 已修复问题

- MCP 在途调用取消与截止无效；成功更新回执被当前大文件挡住；响应预算缩小页长后游标不能续取。
- 合法的大元数据导致发布成功但 MCP 收据及查询响应超限：改为严格的紧凑投影，完整 Web/SDK 数据保留。
- 公开目录使用原始 Markdown 标题导致私有链接目的地泄漏：目录仅使用可见文字。
- 暂时无法读取原稿时误永久下架：改为 503，确认实际删除后才下架，覆盖移动、同步和权限恢复。
- 元数据保存后刷新失败，以及服务端两次源读取之间发生修改，可能让旧预览携带新哈希：正文和身份绑定同一次读取，发现变化时首次发布只要求复核。
- 两套旧工作区测试加载器补齐真实博客模块映射，未放宽行为断言。
