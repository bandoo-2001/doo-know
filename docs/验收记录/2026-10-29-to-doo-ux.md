# To Doo 交互简化验收记录

## 实现

- 打开 To Doo 直接进入任务列表；左侧和手机快捷入口提供收集箱、今天、近七天和所有任务，清单直接可达，其他模块收进更多功能。
- 列表顶部支持回车添加、自然日期识别、继承当前清单及今天的安排。快速录入和详细添加共享恢复草稿，展开详细添加时隐藏快速提交入口。
- 列表、看板、四象限在内容区切换；筛选、排序、批量及管理操作按需展开。完成项默认折叠。
- 详情使用可展开分组；宽屏与列表并排展示，手机保留整页详情。保留明确保存、附件、资料、成果和高级功能。
- 常用任务范围保存在 taskFilter 路由参数中，支持刷新和历史导航；首载会根据资料集时区校正日期。
- 侧栏独立分页载入清单目录；清单编辑及原请求重试成功后同步目录。新建会话固定原始清单身份，切换清单后不会误删另一份草稿。
- 修复搜索任务时关联执行实例与时间块被过滤的问题。搜索范围限于任务标题、说明、完成标准和有效单期覆盖标题；不通过成果或记录的内容隐式命中任务。

主要代码位于 `apps/web/components/ToDooWorkspace.vue`、`apps/web/components/to-doo/`、`apps/web/to-doo.css`、`apps/web/to-doo-presentation.ts`。导航透传在 `navigation.ts`、`Workspace.vue`、`AppsWorkspace.vue` 和 `to-doo-workbench.ts` 中定点调整；查询修复在 `packages/core/to-doo/queries.ts`。现有其他未提交修改保留。

## 验证

- Vitest：34 个文件、245 项相关测试通过，涵盖 To Doo、MCP 授权、领域整合、浏览器导航及 Workspace 导航。原 Workspace 测试夹具补齐已有 app-shortcuts 依赖的映射后，15 项导航测试均通过。
- Playwright：原 5 项与新增 9 项场景在桌面和手机各完整通过；最后增加的清单删除重试场景另在两个平台通过。共 30 项平台场景通过。
- 新增行为先复现失败再修复：快速添加、首载跨时区、清单删除和删除重试、搜索执行上下文及搜索授权边界。
- `npm run typecheck`、`npm run build`、`git diff --check` 通过。构建仍有第三方依赖的模块指令提示，不影响成功构建。
- 独立审查用真实 service 与 agent-port 的隔离夹具确认：未授权或范围外的成果、记录关键词不能间接命中任务，单期覆盖标题仍可检索。
- 浏览器测试使用独立临时知识库、数据库及服务器，未修改真实任务数据。
