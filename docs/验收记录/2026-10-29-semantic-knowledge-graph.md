## 浏览器验收内容

真实认证与 API 创建 Markdown，验证后台无需打开页面就分析；通过页面配置 Ollama，再切换 OpenAI 兼容接口，保存与测试均成功。密钥保存后输入框清空且 API 仅返回配置状态。

在页面中审核带准确原文的模型关系、改写关系名称、查看已确认项，添加实体别名并展开局部，保存视图及下载 JSON。问答夹具故意等待 16 秒，验证模型请求不会被通用 15 秒客户端预算提前终止；返回引用可打开原文 `#L3`，原文内容保持完整。覆盖暂停和继续任务。

原引用流程验证搜索、孤立项、一至两跳、列表、打开原文、返回与刷新。桌面/手机均检查无水平溢出、无页面脚本异常，默认不同时显示卡片列表与画布，不显示空详情侧栏。截图与日志位于忽略目录 `.local/semantic-graph-artifacts/`。

## 已修复并复验的重点问题

- 提前拒绝的模型响应必须关闭连接，不能绕过并发和超时；明文私网检测使用真正 IP，不接受伪装成私网的域名。
- 旧任务 epoch 不得删除新任务结果；关闭自动分析保留已有有效图谱，抽取指纹排除纯调度/版本字段。
- 模型与分析器的实体/关系/quote/输入预算对齐；省略明确标记部分结果。
- 任意已分析尾部资料可搜索、聚焦或进入审核；先授权过滤再聚合与分页。
- 探索/审核/问答按 16 MiB 来源 JSON 总预算逐条加载；状态轮询不读取 JSON 和全库文件。
- 人工关系支持断开笔记间创建，参与局部、合并和路径探索；相似开关独立于语义候选开关。
- 同一用户的筛选结果和全局状态 revision 一致，静态资料不被每轮重复加载。
- 后台更新保留未提交的关系编辑，确认后同步取消候选样式；搜索后展开局部能够加载真实邻居。
- 未知命令结果重试复用完整请求身份，避免重复视图/关系；无 `crypto.randomUUID` 的 HTTP 预览仍可生成安全请求 ID。

模型、引擎、UI 和最终全栈均经过独立审查，相关修复以原始合成探针或回归复验，无剩余已确认实质发现。

## 真实使用前提与限制

本轮验证模型协议、数据流和可操作页面，未安装模型权重、未读取真实 API 凭据、未调用真实外部模型。用户配置后仍应测试服务连通性和模型抽取质量。基础本地分析可直接使用，不能将词项共现/相似度当作已证实事实。

平台 20 MiB 文件上限、256 分块、单任务时限、每篇实体/关系/证据预算，以及探索来源/字节/节点/边预算均保留。超限会报告部分结果或截断。使用与数据细节见[知识图谱](../知识图谱.md)，调研依据见[实现参考与取舍](../design/semantic-graph-research.md)。
