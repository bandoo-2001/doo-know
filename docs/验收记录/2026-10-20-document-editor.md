## 已实现能力

| 内容 | 实现 |
| --- | --- |
| 编辑方式 | 文档编辑、Markdown 源码、阅读；源码可同时预览；跨方式共享草稿和撤销 |
| 排版 | 正文、标题 1–5、既有 H6 保全、粗体/斜体/删除线/行内代码、引用、分隔线、列表/任务、代码语言 |
| 表格 | 标准 Markdown 表格、增删行列、整列对齐、删除及撤销；复杂表格明确选择文本或取消 |
| 链接与附件 | 链接文字/地址/标题、授权图片、替代文字/标题、PDF、文件粘贴、异步插入书签 |
| 保存与恢复 | 继续使用现有手动保存、版本冲突、幂等回执、本地 Markdown 草稿；组合输入完成后才生成快照 |
| 兼容 | 未知内容保留原文；跨段引用、超限或大文件回退源码/原大文件通道；旧偏好继续保留 |
| 阅读 | 普通预览、分享和大文件片段使用一致的非交互任务状态展示 |

Tiptap 核心及扩展固定为 3.32.0（MIT），使用核心 Editor 接入 Vue 生命周期；没有使用在线转换、CDN 或付费能力。文档模型仅为编辑投影，磁盘、接口和草稿正文仍是 Markdown。

## 内容保全证据

38 份合成语料涵盖 CRLF/BOM、空文档、尾部空白、中英文/emoji、表格、任务、相对资源、代码围栏、引用定义、Frontmatter、HTML/注释、项目样式及未知语法。原生引擎全篇往返会改变其中 34 份，故产品没有直接采用全篇默认序列化保存。

产品按安全单元保存原文切片；无编辑返回相同字符串，只有实际编辑的单元重新生成并经过模型重建和独立可见文本核对。未知或无法证明安全的内容保留为不可隐式删除的原文块，或者整篇使用源码。新增用例证明引用块、列表中的引用定义同样触发源码回退，不会在编辑后变成字面文字。

| 风险 | 验证与处理 |
| --- | --- |
| 浏览或切换改写内容 | 20 次切换无写请求、无脏状态；原 Markdown 相同 |
| 未知语法被删 | 全选删除不能隐式删保留块；明确删除可撤销；原文可复制并跳转源码 |
| 草稿恢复被旧投影覆盖 | 恢复源码专用草稿时阻断旧文档回写，完整文本保留 |
| 组合输入被保存截断 | 等待组合结束；无法表示时保留可见现场和未保存状态，拒绝保存，提供恢复副本下载 |
| 保存已成功但回执丢失 | 保持原幂等请求与不可变快照，后续输入仍未保存，不重复写入 |
| 上传迟到或选区失效 | 笔记/代次/版本/投影书签核对；失效时需重新选择位置，不能插入其他笔记 |
| 反向选区插入 | 使用规范化区间，插入后定位末尾；源码和文档插入均支持撤销 |
| 粘贴结构被清洗吞掉 | 在清洗前判断原结构；checkbox 状态、定义列表、上下标及不支持样式须明确选择纯文本或取消 |
| 代码或样式被截断 | 围栏长度按代码内容选择；未知元信息保留；未闭合样式标签整体保护 |

恢复副本包含原 Markdown、当前文档模型和保留块原文，只是异常恢复材料。不会用该 JSON 替换正常的 Markdown 存储合同，也不会在转换失败时显示“已保存”。
