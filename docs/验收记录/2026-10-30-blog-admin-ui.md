## 界面变化

- 统一博客区域的字号、标题层级、控件尺寸、间距、页面底色与面板；桌面正文 15px、辅助文字 13px，主要操作 42px，手机操作至少 44px。

## 浏览器发现并修正的问题

完整回归初次为桌面 13/13、手机 12/13。手机专题连续选文时，长标题候选按钮在限高的纵向 flex 列表中被压缩到 44px，文字和点击区域覆盖了相邻项，导致选入错误文章。指针命中和立即记录的文章 ID 复现了这个路径，问题发生在保存前。

候选按钮设置 `flex-shrink: 0` 后保留自然高度；选择模型、后端和原有发布断言没有修改。补充回归逐次核对文章 ID、人工保存后的顺序及没有触发主页发布；五组手机组件复验和最终完整 API 场景均通过。另修复了可滚动窄菜单的键盘焦点外框裁切。
