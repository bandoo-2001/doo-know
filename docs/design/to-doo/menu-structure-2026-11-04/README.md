模块栏放返回、任务、日历、四象限、专注、习惯、纪念日、复盘，通知和设置位于底部。上下文栏依次是任务标题、我的待办、目标、我的清单。

建议落地逻辑宽度：模块栏56–64px，上下文栏192–216px；菜单文字14px、分组标题12px、行高36–40px。图片是静态概念，最终尺寸及各模块菜单仍需用真实组件校核。
