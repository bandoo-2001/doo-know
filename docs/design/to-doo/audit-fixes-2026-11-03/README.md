同名JSON保存截图来源提交、主题、尺寸、业务时间及窗口身份/截图后可见状态。成果笔记等窗口的字段和主操作在捕获前后核对；目标主题从首帧加载，等待画面稳定后保存。源码最终冻结提交及实际验证结果见 [验收记录](../../../验收记录/2026-11-03-to-doo-audit-fixes.md)。
