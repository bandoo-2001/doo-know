# 非 ToDoo 平台实际浏览器截图

打开[场景图库](index.html)，可以按中文标题、场景名或来源编号检索，点图查看原始尺寸。[实测索引](effective-index.json)逐条列出原始运行、页面状态、角色、视口、源码提交、应用指纹、原图 SHA-256、设计引用、目标边界与真实操作回执。[逐图审查](reviews/)与[原始全量及定点结果](reviews/validation-results.json)分别保存。

每个视口和场景优先展示最近的有效截图。原始的失败、未挂载、历史错误状态和探针异常均保留。普通父页面只证明镜头里的内容。例如，打开设置页不能证明屏幕外的冲突提示可见。滚动补图、独立下载的 HTML 和修复作者的定点图各自标识。真实组件遇到模拟断网、延迟、只读故障模型或隔离权限时，具体注入范围列在对应记录的 faultInjection。未执行的保存、发布或授权保留为未验证操作。

浏览器 theme 字段表示请求的色彩偏好。已发布博客如选择浅色，会按站点配置显示浅色。公开文章 system-theme 场景显式保存跟随系统的站点配置，核对真实 CSS color-scheme 并还原隔离站点设置。Chromium 触屏宽度、键盘事件与截图不能验证实体键盘、操作系统选择器、系统分享、实际打印或外部投递。

原始运行目录含大型图片、侧车、失败诊断和逐阶段日志，由 [runtime-artifacts.json](runtime-artifacts.json) 登记完整外部归档。将归档解压到新目录，可按清单中仓库相对路径逐文件比对字节数与 SHA-256；解压得到的 docs/design/platform-unification-2026-11-05/runtime/index.html 可离线查看。设计原图通过[独立设计归档](../image-artifacts.json)恢复。Git 保存图库、实测索引、哈希、逐图判断和实验工具。

## 验证边界

原始全量单元运行 458 个文件（430 通过、25 失败、3 跳过），3729 项测试（3621 通过、86 失败、22 跳过）。25 个失败文件后来单独重跑，4 个渲染测试文件 57 项通过，另外 21 个文件在已有 Python/模型环境中 84 项通过。

原始全量 E2E 桌面 580 通过、51 失败、5 跳过，手机 592 通过、35 失败、9 跳过。原始失败包括历史夹具、已调整的导航断言、共享提醒遮挡及其他尚未独立排除的交互问题。[桌面失败逐项分类](reviews/desktop-original-failures.md)和[两个设备的全部失败标识](reviews/validation-results.json)可供复核。定点重跑、独立截图和发行门禁各自记录，均未覆盖这些原始记录。

故障与限制包括原生 Stats 在锁定版本的移动菜单中未挂载、图谱同名节点可能拥挤、未分类 Git 503 等低优先级文案，以及部分控件透明内部 input 的中心命中探针。判断控件可用性时需同时查看真实操作和对应可见元素；未复现或仅检查 SHA 的案例保留其范围。

设置和博客补拍保留各状态自身的限制。历史卡片在升级前只展示目录版本。最终卡片展示已安装版本，并在有更新时另列目标版本。三种宽度的升级前后截图和实际 installedVersion 均附在[最终升级回执](targeted-regressions/plugin-upgrade-labels-three-width/receipt.json)。短屏博客错误反馈、焦点与按钮需同时核对主图、控件图和原生焦点回归。其他留档项包括放弃按钮的边缘对比度、凭据未知 503 的通用文案、附件上传失败队列的紧凑样式、图谱空数据与实际外部投递。具体范围见各审查文件。

移动核对的补帧聚焦实际拒绝和保留参数，截图中的说明框未覆盖完整移动窗口的底部按钮。手机首次打开脑图与先在桌面打开后缩小窗口是不同状态；在极短视口，节点位于内部可滚动画布内仍可能在首屏以下。图谱空数据只覆盖空态；透明选区和控件焦点的限制保留在各行。
