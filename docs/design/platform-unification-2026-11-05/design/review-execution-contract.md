# 逐图审查合同

这是生成设计的功能/风格审查，不是运行验收，也不是整套图稿全局放行。不得将已完成 ToDoo 交付当作本轮完成。

- 每张实际 `view_image`，对照其 sidecar 的完整实际提示词、所选状态、真实基线和当前组件模板。批次 manifest 保留 sourceContracts、sourceRefs、字段、动作、守卫、角色和原始计划。
- 当前源码/角色/API约束优先，实际基线用于确认所选状态；生成器若从源码补长页或合成未捕获状态，逐项核对条件，不能把源代码派生示例说成运行成功。
- 核对现有导航、输入/只读字段、操作、禁止/忙状态、错误或降级说明、计数一致性、权限、条件字段和状态组合。示例正文可变化，固定控件文案或语义不得变；样例搜索/数量/选择要能由实际行为产生。
- 完整页面保留自己的真实宿主。局部窗口/浮层/状态图可只画组件并在元数据绑定父页/角色，不必重画宿主；若画宿主则不得虚构入口。图外 source-ID caption 可以元数据承担，不因缺caption单独拒绝。
- 私有、公开阅读、guest编辑、OAuth和首次设置的权限边界独立。不得新增注册/找回/分享密码门/团队/AI能力。现有 To Doo 应用卡片保留，不能把禁止全局ToDoo重品牌误读为删除该卡片。
- 主页面只画一个连贯状态，明确状态矩阵才可分行/分区对照互斥分支；不能要求所有隐藏字段/状态在单页同时出现。共享状态按实际renderer/message/data/guards逐项映射，不能用父图掩盖独特窗口。
- 动态博客品牌色/模板差异、画布内容颜色属于用户/数据配置；统一视觉不应消除这些能力。共享边框、字体、密度与布局对照 `style-contract.md`。
- 仅栅格轻微纹理或近似像素尺寸记录CSS实现指导，不重复无收益生图；清晰度不足以核对字段、主要按钮被裁切、结构性宿主缺失等仍须指出。意图尺寸不是实际PNG尺寸，静态图不能验证焦点/键盘/权限执行。
- PB060只保留HTTP状态/错误契约，没有专属HTML页面，不生造访客错误页；PB016只画现有SetupWizard条件notice，不声称普通公开路由可达或可浏览器创建账号。
- 每图审查写 `design/reviews/<PNG stem>-review.json`，含assetId、实际PNG SHA256（`reviewedImageSha256`）、查看方法、sourceRefs、verdict=`pass|needs-revision`、functionalFindings/styleFindings、明确requiredCorrections、验证边界。没有实际看过或无法核实不能写pass。
- 修订只复核本轮目标和发生变化的内容；旧审查/旧PNG保留，新SHA另写报告。根目录catalog只认可当前版本的匹配SHA审查。
- 不生图、不改产品或他人的计划/sidecar、不跑已报告同源码测试、不内嵌图片或base64给根线程、不派子代理。批次简报只给计数/路径/阻断项。
- 全套图稿完成后另行审查覆盖、跨页面风格与功能一致性；任何单批通过都不能替代该全局门槛。
