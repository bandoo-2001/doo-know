# 文档编辑内容保全验证

日期：2026-10-20。仅使用合成语料，不读取或修改私人知识库。

选定 Tiptap 3.32.0 及其 ProseMirror 封装，核心和相关扩展固定同一版本，npm 元数据许可证 MIT；项目本地安装。使用核心 Editor 对接 Vue 3 生命周期，未保留未使用的 Vue 包装依赖。

38 份兼容语料位于 `tests/fixtures/editor-compatibility/cases.json`。原生 MarkdownManager 解析再序列化只有 4 份完全保持输入，34 份发生格式改写，因此不能直接把该序列化结果作为整篇保存内容。

采用原文安全单元和原文保留块；未编辑的单元复用原字符串。文档模型的已编辑单元必须序列化后重新解析并通过 schema 语义对比，才接受事务；未知内容、引用依赖不能安全处理时保留或使用源码。编辑器 JSON 不作为持久正文。

原文层、文档投影、会话历史、粘贴/附件、安全及设置迁移的 114 项专项单测通过，包含 38 份语料原文往返、编辑相邻正文后保留其他单元，以及引用块/列表内定义的保守回退。保存、故障、输入法及性能的实际证据分别记录，不把转换层通过等同于完整交付。

试验原始输出在 `.local/document-editor-probe/results.json`，试验入口在同目录 `probe.mjs`；验证命令 `node .local/document-editor-probe/probe.mjs`。产品回归命令及实际结果见[实施验收记录](../验收记录/2026-10-20-document-editor.md)。
