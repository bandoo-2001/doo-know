### 覆盖内容

- 正确/错误登录、关闭注册、异源与 CSRF 拒绝、退出失效、本机重置密码撤销会话、拒绝第二个账号。
- 匿名拒绝目录、笔记、搜索、附件、历史和回收站。
- 创建真实中文 .md，拒绝同名；未保存输入不写文件；Ctrl/Cmd+S 保存。
- 使用 mtimeNs 字符串检查版本；外部修改、再次变化、双标签页均触发冲突；取消保留输入，确认后才覆盖。
- 分享读取最新已保存文件，包括网页和本地修改；未保存不公开；复制、重置、取消、删除与缺失文件使旧入口失效。
- 已保存引用的图片/PDF 可访问；未引用、移除引用、其他笔记附件和撤销后的入口拒绝访问。限制类型、签名和 10 MiB；阻止危险 HTML、脚本链接、远程图片、隐藏目录与软链接。
- 原文与历史保留、按版本恢复、回收站恢复位置占用拒绝、恢复保持私有、重启后身份保持。
- 写入或历史备份失败，原文件与编辑内容不丢失、不标记已保存；会话失效后重新登录继续保存。
- 迟到的保存/打开响应不能污染另一篇笔记；回收站源文件无法删除时仍可重试恢复。

## 独立审查与修复

一次独立只读代码审查发现三项 Important，均先写失败用例再修复并跑完整验证：

1. 迟到保存响应可能把另一篇正文写入错误 ID：操作固定笔记与视图代次，过时结果不改当前文档；桌面/手机用真实服务响应延迟回归。
2. 恢复 unlink 失败使回收站记录消失：恢复使用独占复制，元数据与移除原件在同一事务内处理；失败保留可重试状态和原始字节。
3. 容器缺少管理入口：编译并交付 account/backup/restore 的生产 CLI，更新容器操作说明；直接 Node 入口验证通过。

审查未发现有证据支持的 Critical，未再安排重复审查。作者完成修复与回归。未遗留审查 Minor。

## 限制及未执行操作

- 构建成功，但单个前端 JS 约 1.15 MB（gzip 约 390 KB），Vite 提示体积较大；尚未做进一步分包优化。
- 主机没有 Docker 命令，容器镜像未实际构建；提供了模板和经过编译验证的 CLI。HTTPS、systemd 实际启用与公网验证未执行。
- 保留设计中的边界：外部进程不参与应用锁；不保证最后一次 mtime 检查与原子替换之间的跨进程实时协作。应用内写操作同步串行。
- 未模拟突然断电的完整跨文件/数据库事务保证；有正常文件系统失败与一致性备份恢复的验证。备份前仍须暂停应用和外部编辑。
- 撤销阻断下一次请求，不能收回访客已下载或浏览器内存中的内容。
- 源码与知识库均未自动提交、推送、合并或发布。知识库已有文件和未提交资料保留，只新增本次交付记录。
