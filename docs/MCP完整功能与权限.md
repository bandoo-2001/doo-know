# MCP 完整功能与权限

MCP 插件 1.3 提供 **110 个工具**，覆盖当前知识库、博客和 To Doo 的业务能力，并保留原有 32 个工具。工具名称和严格参数可通过客户端工具发现读取；完整目录使用 `nextCursor` 分页。

## 业务能力

| 领域 | 已接入能力 |
| --- | --- |
| 知识库 | 搜索、正文与章节读取、创建和修改、目录整理和撤销、历史版本查询读取恢复、笔记及目录回收站、反向链接、最近和收藏、附件、可编辑图形及白板关联、单文档和整库资料包导入导出、分享、维护设置与可处理的冲突 |
| 博客 | 文章列表、分类标签、管理详情、草稿创建编辑、文章删除、站点设置、发布与撤下、不可变发布版本及封面资源、图块和附件、完整元信息与 HTML 下载、带图发布 |
| To Doo | 目标清单、章节标签视图模板、任务与执行实例、重复例外、批量与级联、依赖和时间安排、专注、习惯打卡、纪念日、成果证据与复盘、统计设置、提醒和设备管理、日历与私有订阅、附件、JSON/CSV/ICS 导入及 JSON/ICS 导出、可恢复的成果笔记 |
| 共享传输 | 大内容上传、下载、进度、取消、哈希校验、续传、提交请求占用、临时清理和主人登录下载 |

## 授权

在「设置 → 插件与连接 → MCP 服务」选择业务能力及资源范围。新插件需要兼容 API 1.3 的宿主；升级插件后，新增权限仍须主人明确选择，已有连接需要重新授权相应能力。

| 权限 | 用途 |
| --- | --- |
| 知识库读取、编辑、整理、归档、索引 | 原有内容与目录操作；恢复仍核对当前资源和版本 |
| 分享管理 | 创建、调整、轮换和撤销资料分享；编辑分享还需资料写权限 |
| 资料维护 | 整库资料包导入导出及维护操作；全库操作需要整个知识库范围 |
| 博客查看、草稿编辑 | 查询和修改获准文章；源笔记与附件仍受知识库读取权限限制 |
| 博客站点与文章管理 | 管理站点或删除获准文章；站点操作需要站点范围 |
| 博客公开发布 | 明确发布或撤下公开文章；不隐含知识库写权限 |
| To Doo 读取、编辑 | 同时受清单、内容类别和当前对象版本限制 |
| To Doo 导出与分享 | 导出获准数据、管理私有订阅；任务订阅还需任务及日历内容范围 |
| To Doo 外部连接与设备 | 导入、外部日历及提醒设备管理；不会取得无关清单或资料原文 |

完整待办检查点恢复可能改变数据集身份。旧授权会失效，主人可在设置页点击「使用当前数据」，再选择所需权限和资源并重新授权客户端。重新绑定先清空旧权限，不会把旧连接自动扩大到新数据。

## 使用与恢复

- 知识历史：`list_note_revisions` 找版本，`read_note_revision` 按页核对，`restore_note_revision` 使用当前版本及稳定 `requestId` 恢复。
- 博客：先查询文章和当前版本，再创建或编辑草稿。私有修改不会替换公开快照；发布、撤下和分享按用户明确要求执行。
- 待办：`describe_to_doo_schema` 给出所有命令、实体和更新字段契约；`execute_to_doo_command` 和 `save_to_doo_entity` 调用现有业务引擎。`read_to_doo_entity` 可在只读权限下完整分页读取大型数组或模板。
- 结果未知时保留原 `requestId`。旧知识和博客操作用 `operation_status`，新增知识业务用 `get_knowledge_operation`，待办适配器用 `get_to_doo_operation`，成果笔记用 `get_to_doo_outcome_operation`。旧任务命令也可通过 `query_to_doos(receiptRequestId)` 核对回执。
- `accepted` 仅表示任务已接收；查询到 `succeeded` 才确认完成。取消或断开连接不保证回滚已提交修改。

## 大内容与约束

先调用对应领域的开始上传或导出工具，再使用 `append_mcp_upload`、`read_mcp_transfer`、`get_mcp_transfer` 和 `cancel_mcp_transfer`。上传每块最多 16 KiB 原始字节的 base64，下载每块最多 8 KiB；保留原传输 ID 和偏移，重复偏移必须使用相同内容。领域提交前核对长度、哈希、当前权限和资源版本。

完整文件可通过 `get_mcp_transfer` 返回的链接由主人登录下载，链接不携带访问令牌。临时上传保留 1 小时，下载保留 4 小时；取消释放配额，过期数据定期清理。单次上传上限 72 MiB，下载上限 256 MiB，领域自身更小的文件限制继续生效。正文和分块下载共享 MCP 读取速率。请求最多 128 KiB，完整 JSON-RPC 回复最多 64 KiB。

设备首次订阅仍需真实浏览器的 HTTPS 环境和通知许可；MCP 可以查询、配置、测试和撤销已登记设备。图块发布使用绑定源版本的 PNG，渲染结果可由客户端准备后通过传输上传。系统账户、恢复密钥、服务部署等宿主管理操作继续使用对应管理入口。
