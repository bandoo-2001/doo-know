## 用户可见变化

1. 初始设置增加“从 GitHub／Gitee 导入”：填写仓库、凭据、分支和新目录，测试读取连接后导入；此流程按需安装并启用 Git 插件，最终进入知识库工作区。已使用本地目录的用户可在“知识库与存储”或 Git 插件设置中关联云端，沿用已有历史并保留其他远端。
2. “云端同步”提供检查云端、预览后提交并推送、仅推送已有提交、拉取更新与断开关联。原“提交全部变更”仍只生成本地提交。拉取只接受直接前进的历史，保护未保存草稿、未提交文件、忽略文件和待核对的本地 Git 提交；不自动推送、强推、整库重置或自动合并分叉。
3. HTTPS 令牌在服务端按账号、主机加密保存；可选仅在本次服务进程内保留 30 分钟。SSH 为高级选项，需要核对并明确信任主机指纹。秘密不进入浏览器存储、任务记录、Git 配置或命令参数。页面及[使用指南](../Git远程知识库.md)说明准备步骤和读取／推送权限的区别。
4. 仓库任务持久保留进度和回执。推送未知结果核对原提交，不重复提交；拉取重试固定原目标，并补齐目录／索引刷新。拉取后当前笔记和目录自动更新，立即关闭同步面板也不打断刷新；异步期间的新草稿保留。取消导入会传递到插件下载，并停止后续启用／绑定。
5. 后台 `serve` 下载复用本实例已保存的非认证代理，显式环境仍优先。网页插件安装改为立即返回任务、轮询下载／校验／安装进度；请求响应丢失或任务刚好结束时按原回执恢复，合并请求的标识也持久保留。其他用户升级到本版同样获得此修复；网络仍需能访问制品源，平台不自动安装代理软件。

保留 rc.22 的断网保存重试、大文件 Git 恢复提示及原有恢复上限。未改动 MCP 功能、检索模型或独立检索制品。

## 审查与执行裁决

任务级和整分支审查提出的问题均已修复。产品终审复核确认拉取固定目标及刷新、未核对提交拦截、取消与下载进度、检出前容量预检、禁用插件历史元数据处理已解决。最后一项预览发布保护在首次复核中仍存在跨进程窗口：控制器随后使用 SQLite `BEGIN IMMEDIATE`，将已验证本地制品的安装、最终状态核对与写入置于同一保护区，成功提交或失败回滚后释放。真实第二进程在最终读取之后尝试卸载，先复现被覆盖，再验证写入被阻止，事务结束后仍可正常卸载；私有隔离检查 14/14 通过。这一最后修正只涉及私有部署程序，未改变产品源码或制品，未宣称另有一次独立复核。

主要裁决及边界：

- 复用既有隔离工作区和当前发布分支，不迁移主机目录、不覆盖其他工作。后端任务与安装任务的共同接口一起提交，保持每个提交可执行；实现代理按任务单独安排，控制器负责集成与发布。
- 测试传输仅通过构造函数注入执行器工厂，以同一数据库取得工作区许可；配置文件不能注入执行代码。
- 克隆只发布到全新命名目录，即使已有空目录也拒绝覆盖。暂存预算为 1 GiB、100,000 个目录项，保留至少 512 MiB 空间；每 250 ms 检查增长，并在检出前检查对象大小及预计空间。周期检查允许采样间隔中的短暂超出，不是文件系统硬配额；大型历史、子模块和 Git LFS 管理不在本版导入能力内，可先手动克隆再选择本地目录。
- 重试保留同一任务和原始目标；服务重启不会自动重放未知网络写入。已发布克隆只按原目录身份恢复绑定，清理只处理身份一致的自有暂存目录。
- 每次部署取新基线，只升级已安装 Git 并保留启停与配置；用户已卸载时不自动重装。代价是普通本地目录用户需要明确选择远端接入或安装插件，避免替用户改变使用方式。
- 预览发布的短写锁仅覆盖已核对的本地包，期间不做网络下载；代价是其他写入会短暂等待。并发选择改变时停止本次发布，不回写旧偏好。
