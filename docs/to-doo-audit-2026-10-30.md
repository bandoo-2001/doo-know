# To Doo 测试与详情页精简（2026-10-30）

> 历史阶段记录；当前统一布局、实现状态与验收以[唯一规范入口](design/to-doo/unified-ui-v2/IMPLEMENTATION.md)为准。

本轮针对任务主流程、详情编辑、重复与日期安排、资料成果、提醒和日历进行源码排查及隔离测试。初始工作区干净，使用已有独立工作树与项目依赖。所有浏览器任务、知识笔记、账号和数据库均由临时测试夹具创建，没有操作真实待办或发布正式服务。

## 详情页

- 默认展示标题、状态、说明、清单、优先级、截止日期与时间安排。
- 四象限、重复、关联资料、附件、完成标准、子任务、标签与提醒、推进记录和历史集中到“更多详情”。原有功能保留，非空资料显示数量摘要。
- 说明输入框随内容调整高度；时区放到更多选项中，空白表单不再连续展开大量字段。
- 更换任务/执行实例时重新初始化局部界面状态，草稿由工作台保留。
- 窄屏详情增加对话框语义、初始焦点、Tab 循环、Esc 关闭及焦点恢复，关闭后再打开保留输入。
- 保存入口检查非法日期/时间及空白标题；中文输入法组字时不触发保存快捷键。
- 未选来源资料时禁用来源引用输入，避免输入后无效果。

## 验证

单项缺陷使用失败回归确认后修复；纯布局通过真实浏览器截图和控件操作检查。

- `npm test -- to-doo`：46 个文件、387 项通过，覆盖 To Doo、MCP、接口、存储与组件。
- `npm run typecheck`：通过。
- `npm run build`：通过；现有第三方模块仍输出 `use client` 指令提示，不影响构建结果。
- 改动及新增代码的 Prettier 检查、`git diff --check`：通过。
- 独立复查提出的时间块连带版本、重复实例复活、同毫秒删除标记和夏令时事件消失四项问题均补测修复，复核通过。
- `npm run test:e2e -- tests/e2e/to-doo --output .local/todoo-audit-final`：桌面 49/49、手机 49/49，总计 98 项全部通过。两端分别使用独立账号、数据库和服务；覆盖列表/看板/四象限、任务创建编辑完成、日期与重复、草稿恢复、附件与成果、清单、提醒、日历、专注、习惯、纪念日、导入导出、窄屏与深色布局。

## 范围与限制

- 没有上线部署，没有自动修补历史任务中已经存在的不一致数据。
- 桌面系统通知的真实设备授权、网络投递及操作系统行为不在本轮实机验证范围；现有隔离提醒用例仍参与回归。
- 删除恢复沿用现有 `deletedAt` 字段作为事务标记，必要时会按毫秒顺延，避免本数据集中的碰撞。两个离线主机独立生成完全相同的删除时间再合并的情形，仍需独立删除组标识才能彻底区分。
- 本报告记录已检查的范围与可复现缺陷，不代表所有设备及所有输入组合均无缺陷。
